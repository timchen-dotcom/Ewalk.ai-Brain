- 一句話：Claude Code 的 Hooks 不是「提示詞技巧」，而是能在 session/turn/tool-call 生命週期中自動跑的規則層（可做允許/阻擋、記錄、觸發 agent 驗證等）。
- 對 Ewalk.ai 的白話幫助：把「阿順能做什麼/不能做什麼」做成機械化規則（例如阻擋危險 shell、限制寫入路徑、把每次工具呼叫記錄成可稽核 log），降低出包與權限風險，也更利於交付可追蹤。
- 建議動作（需提姆允許後才進 /自我升級）：
  - 抽一個最小可用 Hook 套件：`PreToolUse` 擋危險命令 + `UserPromptExpansion` 覆蓋 slash command 直通路徑 + `PostToolUse` 記錄工具輸出摘要（避免敏感資訊外洩）。
- 來源：
  - Claude Code Hooks Reference：https://code.claude.com/docs/en/hooks
