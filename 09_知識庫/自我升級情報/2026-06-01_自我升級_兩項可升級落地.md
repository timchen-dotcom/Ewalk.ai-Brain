## 可吸收重點

### A) AgentMemory：本地優先的「可檢索記憶」設計

- 用 Markdown 檔作為長期 facts / daily logs / topic notes / scratchpad checklist 的記憶載體。
- 可選擇性加入語意檢索與「選擇性注入」：把相關記憶片段在每回合自動補回上下文（但必須可控）。
- 對我們的關鍵不是「用不用同一套工具」，而是吸收它的結構：本地、可追溯、可回退、可檢索。

### B) AWI：Agentic Workflow Injection（把不可信內容轉成可執行行為）

- 風險核心：把 GitHub issue/PR/comment 等「不可信 event context」直接放進 agent prompt 或讓 agent 產出影響後續 script/工具，會變成注入面。
- 對我們最直接的啟示：外部內容只能當資料；只要要進入「工具調用」或「寫入/對外」，就要先做 allowlist 與輸出驗證。
