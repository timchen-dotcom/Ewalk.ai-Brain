## 可吸收重點

- Open Design：把「設計產物」變成可重跑的 agent 工作流（prototype / deck / template / design system），並能把產物存成可版本控的 artifact。
- Pi Hermes Memory：記憶系統要同時具備「可搜尋、分層、記失敗、防洩漏」，而且要把 Failure Memory 當成一等公民。

## 系統優化判斷

- 高價值：
  - 讓「提案/廣告視覺」產物流程可複製（不再每次從零）
  - 讓「踩坑教訓」可回填（降低返工）
  - 讓「機密」不會進入可回填記憶（降低風險）
- 暫不吸收：
  - 不直接安裝/引入任何第三方套件到 Ewalk.ai 系統（先用流程與文件落地）
  - 不修改全域規則（AGENTS.md / 全域 SOP）直到試點驗證有效
