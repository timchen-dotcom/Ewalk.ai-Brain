### 2) Claude Code：v2.1.152（MessageDisplay hook、SessionStart 直接 reload skills、/usage 更省記憶）

- 來源標籤：Releases · anthropics/claude-code · GitHub（v2.1.152 / 2026-05-27）
- 來源連結：https://github.com/anthropics/claude-code/releases
- 相關工具標籤：#ClaudeCode #工作流 #自動化 #省Token
- 重點摘要：
  - hooks 能在 `SessionStart` 回傳 `reloadSkills: true`，讓「hook 安裝的 skills」同 session 直接可用（減少重啟/重載成本）
  - 新增 `MessageDisplay` hook event：可在顯示時「轉換或隱藏」assistant 文字（對資訊脫敏、縮短輸出、把冗字折疊成摘要很有用）
  - `/usage` 解析大型 session files 改用 streaming read（記憶體用量更平、較不會因檔案大而炸）
  - primary model 找不到時會切到 `--fallback-model`（降低整段 session 連續失敗的中斷風險）
- 對 Ewalk.ai 的白話幫助：
  - 我們最常遇到的問題是「長任務時技能變動、上下文變肥、輸出太長」。這版提供三個可落地的槓桿：skills 熱更新、顯示層輸出治理（MessageDisplay）、以及大檔 usage 統計更穩。
- 建議狀態：可升級（屬於穩定性 + hooks 能力提升；但涉及 hooks 仍需提姆先生允許後再做 PoC）
