## 情報 1｜Claude Code v2.1.128：zip 插件、Worktree 不再掉未推 commit、OTEL 汙染修正

- 來源標題：anthropics/claude-code v2.1.128（Release 摘要）
- 來源連結：https://newreleases.io/project/github/anthropics/claude-code/release/v2.1.128
- 工具標籤：#ClaudeCode #工作流 #省成本 #自我升級
- 熱度/討論理由（若為 repo）：屬於「日常痛點修正型」更新；對長任務與多代理協作的穩定性影響大（Worktree/插件/telemetry 相關）。
- 重點摘要：
  - `--plugin-dir` 支援直接吃 `.zip` 插件包（更容易版本鎖定與分享）。
  - `EnterWorktree` 改為從本地 `HEAD` 開分支，避免把尚未 push 的 commit 直接丟掉。
  - Bash/hooks/MCP/LSP 子程序不再繼承 `OTEL_*`，降低「CLI 自己的 tracing 設定污染到被執行程式」的非預期問題。
  - 另含 MCP 連線/工具顯示與一些輸出/互動修正（偏可靠度）。
- 對 Ewalk.ai 的白話幫助：
  - 我們如果有用 Claude Code 跑長任務（多次 worktree、反覆迭代、插件擴充），這版是在「少踩坑」：更不容易因為工作樹/分支基準錯誤而回退或遺失進度。
  - zip 插件支援意味著：內部可以把固定版本的插件當成「交付用工具包」，更容易複製到不同機器/同事環境，減少「你那邊可以跑我這邊不行」。
- 建議狀態：**可升級**
- 需要提姆確認：
  - 目前團隊使用 Claude Code 的版本與更新策略（是否允許自動更新、是否先在測試環境升級）。
