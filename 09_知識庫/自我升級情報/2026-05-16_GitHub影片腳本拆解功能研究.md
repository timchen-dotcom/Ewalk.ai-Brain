# GitHub 研究員情報｜影片腳本拆解功能研究

日期：2026-05-16
研究員：GitHub 研究員
任務：找出可強化「影片腳本拆解員」的開源影片處理能力

## 今日重點

影片腳本拆解員不應只依賴「看影片後憑感覺摘要」，而應建立一條可驗證的素材處理管線：

```text
影片 metadata
↓
字幕 / 逐字稿
↓
音訊轉錄與說話人標記
↓
場景切分與代表畫面
↓
時間軸對齊
↓
段落功能拆解
↓
品牌可拍攝腳本
```

## 值得關注 Repo

| Repo | 功能 | 對影片腳本拆解員的幫助 | 導入判斷 |
| --- | --- | --- | --- |
| [yt-dlp/yt-dlp](https://github.com/yt-dlp/yt-dlp) | 影音 metadata、字幕、縮圖、音訊抽取 | 取得影片標題、描述、字幕、縮圖與基本素材 | 高，優先作為素材入口 |
| [openai/whisper](https://github.com/openai/whisper) | 多語音訊轉文字、語言辨識、翻譯 | 沒有字幕時可轉成逐字稿 | 中，需要本機模型與 ffmpeg |
| [m-bain/whisperX](https://github.com/m-bain/whisperX) | word-level timestamps、speaker diarization、VAD | 對齊台詞時間、分辨說話者，適合訪談 / 劇情廣告 | 中高，但需要較多環境與可能需要 Hugging Face token |
| [Breakthrough/PySceneDetect](https://github.com/Breakthrough/PySceneDetect) | 場景切分、切出片段、保存代表畫面 | 把影片拆成鏡頭段落，讓拆解不只靠文字 | 高，適合做視覺段落證據 |
| [Zulko/moviepy](https://github.com/Zulko/moviepy) | Python 影片剪輯、片段、合成、字幕疊加 | 產生內部測試 cutdown、加字幕或對照片段 | 中，適合驗證與內部 rough cut |
| [DAMO-NLP-SG/VideoLLaMA2](https://github.com/DAMO-NLP-SG/VideoLLaMA2) | Video-LLM，影像 / 音訊理解 | 可作為未來「影片內容理解模型」觀察 | 暫不導入，非商用限制與硬體成本較高 |

## 可用做法

### 1. 證據優先順序

影片拆解時，資料可信度應排序如下：

1. 使用者提供原始影片檔與授權說明
2. 官方字幕 / 手動字幕
3. yt-dlp 可取得 metadata、字幕與縮圖
4. Whisper / WhisperX 自動轉錄
5. PySceneDetect 場景切分與代表畫面
6. 外部報導或社群討論
7. 純肉眼觀察與推測

任何低於第 4 級的內容，都要標註「推測」或「架構拆解」，不得寫成逐字稿事實。

### 2. 影片腳本拆解標準輸入包

每次拆影片，若工具與權限允許，應產出：

```text
metadata.json
captions.vtt / captions.srt
transcript.md
scenes.csv
keyframes/
notes.md
```

### 3. 三層拆解法

- 文字層：台詞、字幕、旁白、CTA。
- 視覺層：場景、鏡頭、人物動作、字幕卡、產品露出。
- 節奏層：鉤子、反轉、情緒高點、品牌植入點、行動呼籲。

## 對 Ewalk.ai 的幫助

- STAR Color 之後可以更穩定拆外部 Reels / YouTube 廣告，不會只得到心得摘要。
- 社群主編可以拿到「時間軸 + 片段功能」的內容，不用重新看完整影片。
- 設計企劃可以直接看到關鍵畫面與分鏡，不只看文字腳本。
- 客戶成功經理能快速判斷哪些素材缺口要跟客戶補。

## 導入成本 / 風險

- yt-dlp：外部平台規則常變，YouTube 可能阻擋字幕或需要更新；下載素材涉及授權，內部研究可用，商用發布要確認。
- Whisper / WhisperX：轉錄會有錯字、時間軸偏移；WhisperX diarization 不是完美，且可能需要 GPU / Hugging Face token。
- PySceneDetect：只能切出視覺變化，不理解劇情意義；仍需腳本拆解員判讀段落功能。
- MoviePy：適合內部 rough cut，不應直接產生對外商用素材。
- VideoLLaMA2：研究預覽、授權限制與硬體成本都高，暫列觀察。

## 建議是否升級

建議升級，但分兩階段：

### 立即升級

- 更新影片腳本拆解員入職手冊，加入「證據優先順序」與「影片標準輸入包」。
- 更新短影音腳本拆解 SOP，加入「文字層 / 視覺層 / 節奏層」三層拆解。
- 更新 Prompt，要求標註資料來源層級與不確定事項。

### 待批准試點

- 建立本機 `video-intake` 小工具，先只做 metadata、字幕、場景切分、代表畫面，不做素材商用下載。
- 若要啟用 WhisperX，需要提姆先生批准環境安裝與 Hugging Face token 使用規則。
