### 5) Prompt Compression：Telegraph English（用「語意重寫」取代刪字，50% token 仍保 99.1% 關鍵事實）

- 來源標題：Telegraph English: Semantic Prompt Compression via Structured Symbolic Rewriting
- 來源連結：https://arxiv.org/abs/2605.04426
- 相關工具標籤：#省Token #自我升級 #工作流
- 重點摘要：
  - 提出一種 prompt 壓縮協定：把自然語言重寫成「符號豐富、結構化」的方言（拆成 atomic fact lines + 約 40 種邏輯/關係符號）
  - 文章回報：大約 50% token reduction 時，在 GPT-4.1 上能保留 99.1% 關鍵事實正確率，並在多模型/任務上優於 token-deletion 類方法
- 對 Ewalk.ai 的白話幫助：
  - 我們最常遇到的省 token 失誤，是「摘要把限制條件與禁忌丟掉」。TE 的做法比較像把內容轉成「可檢索的規格化 fact list」，更適合用在：客戶需求、交付約束、禁做事項、品牌語氣這種不能丟的上下文
- 建議狀態：先觀察（先抽成一個「交付約束壓縮格式」模板，不直接改全域規則）
