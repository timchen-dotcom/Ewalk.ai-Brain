## 可吸收重點

### A) Codex：把「可交付型長任務治理」納入升級驗收

- 新價值不只是版本號，而是 `goal mode`、`remote resume`、`browser annotations`、`access tokens` 這些能力是否真的讓長任務更可追蹤、可交接。
- 升級後不能只驗證「能不能跑」，要驗證「任務狀態能不能看懂」、「非互動式身分能不能安全使用」、「中斷後能不能恢復」。

### B) agentmemory：先吸收治理能力，不急著安裝

- 現階段最值得學的不是部署方式，而是：
  - 多 Agent 記憶隔離
  - replay / viewer 可回看
  - 成本感知
  - 每段記憶都能回到原始證據
- 這些能力比「先接上語意搜尋」更重要，因為它們直接影響阿順未來是否能稽核 AI 員工。

### C) Parallel context compaction：長內容先切塊，再整合

- 長任務省 token 的重點不是做更短的整體摘要，而是先把長文切成區塊，各自抽規則，再做跨區塊整合。
- 這個做法適合套用在自我升級情報、逐字稿、月報素材池、長討論紀錄。

## 系統優化判斷

- 高價值：
  - Codex 升級 SOP 已補上長任務治理檢查點。
  - AgentMemory PoC 已補上角色隔離、replay / viewer、本機風險邊界。
  - 記憶抽取 Prompt 已補上長內容切塊壓縮規則。
- 暫不吸收：
  - 不直接安裝任何第三方 memory server。
  - 不把 Codex access tokens 直接接到正式排程或高風險流程。
  - 不把 parallel compaction 寫成全域強制規則，先留在 Prompt / 工作方法層。
