# 自我升級情報

這裡存放阿順每天從 GitHub 與公開開源討論中蒐集到的自我升級情報。

## 蒐集主題

- 優先 AI 工具：Codex、OpenClaw、Claude Code、Gemini、ChatGPT、Images 2.0、即夢 2.0 / 國際版、Nano Banana
- 知識蒸餾
- Agent 自我優化
- Prompt / Skill 改善
- Skill prompt budget / skill-cleaner
- 省 Token、上下文壓縮、記憶管理
- 多 Agent 分工
- 自動化工作流
- 開源 AI 工具與方法
- 高度討論、快速成長、具實作價值的 AI repo
- 對 Ewalk.ai Command Center 有幫助的流程設計

## 使用規則

- 每日情報只做蒐集、摘要與建議，不直接修改 Ewalk.ai 系統。
- 有用資訊要白話說明：這件事對 Ewalk.ai 有什麼幫助。
- 每則情報要保留來源連結，避免只留下二手摘要。
- 優先追蹤 `優先AI工具追蹤清單.md` 內列出的工具；其他新工具除非明顯能改善 Ewalk.ai 工作流，否則先不收錄。
- 高度討論 repo 可以破例優先關注，但必須說明它對 Ewalk.ai 的具體幫助，不能只因為熱門就收錄。
- 只有提姆允許後，才進入 `/自我升級` 流程，更新 SOP、Prompt、Skill、入職手冊或系統規則。
