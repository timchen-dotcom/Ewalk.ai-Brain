### 2) Gemini CLI：Subagents（把「深挖」交給專家，主線對話省 token）

- 來源標題：Subagents
- 來源連結：https://github.com/google-gemini/gemini-cli/blob/main/docs/core/subagents.md
- 相關工具標籤：#Gemini #subagent #省Token #工作流
- 熱度 / 討論理由（Repo）：同上（Gemini CLI 官方 repo）。文件近期仍在更新，且「subagent 拆分」是典型 token / context 工程做法。
- 重點摘要：
  - Subagent 是主代理可「雇用」的專家，獨立 context loop，降低主線上下文污染。
  - 可透過 `/agents` 管理，或在 `settings.json` 用 `agents.overrides` 做持久化配置（例如提高 `maxTurns`、指定模型）。
  - 內建有不同專家（如 codebase investigator、browser agent 等），並支援以設定啟用/調整。
- 對 Ewalk.ai 的白話幫助：
  - 把「研究型任務」從主對話拆出去：主線只保留決策與交付內容，subagent 做背景調查與驗證，能顯著減少 token 消耗與雜訊。
  - 對我們的「自動化 + SOP」很直覺：每個 subagent 就是一個角色（研究員/驗證員/整理員），更接近團隊分工。
- 建議狀態：先觀察
- 建議下一步（低風險試點）：
  - 針對「大量來源比對」類任務（例如：GitHub 情報蒐集），把「搜尋/比對」交給 subagent，主代理只做篩選與輸出格式控管。
