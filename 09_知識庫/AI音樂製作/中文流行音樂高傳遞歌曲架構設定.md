# 中文流行音樂高傳遞歌曲架構設定

## 用途

建立 Ewalk.ai 製作中文品牌歌曲時的基本架構，讓 Suno AI 生成結果更好聽、更容易記住、更適合剪成短影音，也更容易把品牌訊息自然傳出去。

## 核心原則

好聽且傳遞性高的中文流行歌，通常不是資訊最多，而是記憶點最清楚。

```text
一句核心情緒
一個具體畫面
一段容易跟唱的副歌
一個可被短影音剪走的 hook
```

## 一首歌的三層架構

| 層級 | 目標 | 檢查問題 |
| --- | --- | --- |
| 情緒層 | 聽眾知道這首歌在感受什麼 | 是懷念、安心、心動、自由、遺憾，還是被理解？ |
| 敘事層 | 聽眾腦中有畫面 | 是否有鏡子、街角、燈光、氣味、手勢、場景？ |
| 記憶層 | 聽眾記得一句話 | 副歌是否有一句可以成為標題或短影音字幕？ |

## 建議歌曲結構

品牌歌曲優先使用下列結構，穩定、易懂、適合 Suno：

```text
[Intro]
[Verse 1]
[Pre-Chorus]
[Chorus]
[Verse 2]
[Pre-Chorus]
[Chorus]
[Bridge]
[Final Chorus]
[Outro]
```

### 段落功能

| 段落 | 目的 | 建議寫法 |
| --- | --- | --- |
| Intro | 建立聲音世界 | 用 1 個聲音或場景，例如 vinyl crackle、街角雨聲、髮廊吹風機 |
| Verse 1 | 說現在的痛點 | 寫具體狀態，不急著講品牌 |
| Pre-Chorus | 推升情緒 | 用疑問、轉折或即將做決定的瞬間 |
| Chorus | 交出主 hook | 放歌名、核心情緒、最容易記住的一句 |
| Verse 2 | 加深故事 | 補過去記憶、使用者改變或品牌對照 |
| Bridge | 觀點升級 | 說出這首歌真正想講的價值觀 |
| Final Chorus | 加強記憶 | 重複副歌，但可多一句品牌主張 |
| Outro | 留餘韻 | 用一個畫面收尾，不要再塞新資訊 |

## 中文歌詞可唱性規格

| 項目 | 建議 |
| --- | --- |
| 每句長度 | 8-14 個中文字最穩，太長會被 Suno 唱得擠 |
| 每段行數 | Verse 4-8 行，Chorus 4 行最穩 |
| 押韻 | 副歌至少 2 行有相近尾音 |
| 重複 | Hook 可重複 2 次，但不要整段硬複製太多 |
| 品牌名 | 一首歌最多出現 1-2 次，除非是廣告短歌 |
| 專有名詞 | AI、價格、服務名要少量使用，避免歌變產品說明 |
| 情緒詞 | 少用抽象詞，多用畫面替代 |

## 高傳遞 Hook 設計

副歌需要至少有一句能被剪成 5-8 秒短影音聲音標籤。

### Hook 公式

```text
具體物件 + 情緒動作 + 品牌價值
```

範例：

```text
讓顏色回來，也讓溫度留下
不是換一種顏色，是找回自己的樣子
鏡子裡的我，終於不用再躲藏
```

## 品牌歌曲的資訊比例

品牌歌曲要像歌，不像簡報。

| 內容 | 建議比例 |
| --- | ---: |
| 情緒與畫面 | 60% |
| 使用者痛點 | 20% |
| 品牌賣點 | 15% |
| CTA / 口號 | 5% |

## Suno 寫法注意

- Style of Music 用英文寫，歌詞用繁體中文寫。
- 段落標籤清楚即可，不要在歌詞區塞太多技術指令。
- 如果要強化副歌，可使用 `[Big Chorus]`、`[Final Chorus]`，但不要每段都下指令。
- 想要口語感，可以加入 `[Spoken Intro]` 或 `[Soft Spoken Outro]`。
- 想要短影音可剪，讓副歌第一句直接成立，不要鋪太久。

## 品牌歌曲驗收表

| 檢查項目 | 通過標準 |
| --- | --- |
| 5 秒記憶點 | 是否有一句聽完會記住 |
| 15 秒剪輯點 | 是否能剪成 Reels |
| 情緒清楚 | 是否知道這首歌在講什麼感受 |
| 品牌自然 | 品牌沒有硬塞 |
| 畫面具體 | 至少 3 個具體場景或感官細節 |
| 副歌可唱 | 沒有過長或拗口句 |
| 可延伸 | 能改成不同曲風或廣告短版 |

## 常見失敗

- 歌詞像文案，不像人會唱的話。
- Verse 資訊太密，副歌沒有重複記憶點。
- 只有品牌賣點，沒有使用者情緒。
- 曲風 prompt 太雜，一首歌同時要求太多元素。
- 每段都很滿，沒有留給旋律呼吸的空間。

## 最小可用模板

```text
[Intro]
一個聲音或場景

[Verse 1]
現在的痛點與畫面

[Pre-Chorus]
心裡的猶豫或轉折

[Chorus]
核心 hook
核心 hook 的延伸
品牌價值轉成情緒句
可記住的一句收尾

[Verse 2]
更深一層的故事或記憶

[Bridge]
價值觀升級

[Final Chorus]
重複核心 hook
留下品牌主張

[Outro]
一個安靜畫面收尾
```
