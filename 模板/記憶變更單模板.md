# 記憶變更單模板（Memory Patch / Inbox）

用途：把「記憶 / 規則 / 常用結論」的新增或修改，變成可審核、可回退、可驗證的變更單，避免記憶悄悄漂移導致流程不穩定。

使用時機：

- 要新增/修改「長期會被重複使用」的記憶（例如常用 SOP、固定輸出格式、工具使用限制）
- 近期同類任務連續 3 次以上重複解釋/重複踩雷
- 任何可能影響權限邊界、對外發佈、金流、廣告預算的規則變更（必須提姆先生批准）

# intent: <為什麼要改>
# risk: <低/中/高>
