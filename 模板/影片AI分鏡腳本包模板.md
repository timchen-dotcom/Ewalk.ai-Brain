## 10. GPT Image 2 / Images 2.0 分鏡圖生成 Prompt

```text
請使用 Images 2.0 生成一張 16:9 橫式「影視視覺開發板 / storyboard board」。

版面請像專業廣告前期製作板，深色科技感背景，清楚分區，不要像一般海報。

必須包含：
1. 頂部專案列：專案名稱、片長、類型、調性、生成工具。
2. 主角設定區：角色正面、側面、背面、臉部特寫。
3. 核心場景概念圖：呈現本片主視覺與品牌 / 產品露出。
4. Sequence A / B / C 分鏡區：每段 3-5 個 shot，小圖格排列，標示時間與功能。
5. 15 秒或 30 秒時間軸：顯示節奏、相機運動、角色動線。
6. 光線設定：主光、逆光、側光、反光示意。
7. 色彩系統：主色、輔色、強調色，以色票呈現。
8. 鏡頭參數：焦段、景深、幀率、快門感、輸出規格。

視覺風格：
{{視覺風格}}

角色設定：
{{角色設定}}

場景設定：
{{場景設定}}

分鏡內容：
{{Shot-by-shot 分鏡}}

注意：
- 文字以清楚大標與短標為主，小字可以用規整 UI 區塊呈現。
- 不要產生錯誤 Logo、不可讀大量小字、畸形人物或混亂表格。
- 這張圖是給影片 AI 與製作團隊理解分鏡，不是對外發布海報。
```

## 11. Storyboard Grid 規格

| 用途 | 建議規格 | 使用方式 |
| --- | --- | --- |
| 15 秒廣告 | 4-5 格、8 格橫向、或 3x3 grid | 每格一個清楚動作 |
| 30 秒短片 | 8-10 格、3x3 grid、或 3x4 grid | 用 Sequence A/B/C 分段 |
| 60 秒影片 | 15-18 格、4x4 grid 或拆段生成 | 先分段鎖視覺，再合成 |
| 產品 / 流程影片 | 每 2 秒一格 timestamp shotlist | 每格寫清楚景別、角度、動作 |

生成規則：

- 優先輸出單張 storyboard grid，讓 Seedance 2.0 讀取時間順序。
- 16:9 橫式適合視覺開發板；若最終投放 Reels / Shorts，需另外標註輸出為 9:16。
- 正式影片生成前，先在圖片階段修角色、產品、構圖與文字，不要用影片重抽修錯。
- 小字、價格、Logo、品牌字卡不依賴影片模型生成，正式版本建議由剪輯階段疊上。

## 12. Seedance 2.0 動態生成 Prompt

```text
Reference images:
- @storyboard_grid：已確認的分鏡宮格 / 視覺開發板
- @character_sheet：角色三視圖與臉部特寫
- @product_reference：產品 / Logo / 包裝 / 價目表參考

Generate a {{片長}} {{比例}} {{影片類型}} based strictly on @storyboard_grid.
Follow the storyboard sequence of the reference frames in reading order.
Preserve exact shot order, composition, character identity, product appearance, lighting mood, and scene continuity.

Camera movement:
{{慢推近 / 平移 / 俯拍 / 手持微晃 / rack focus / subtle orbit}}

Motion:
{{每個 Sequence 的主要動作}}

Style:
{{品牌調性、光線、色彩、畫面質感}}

Constraints:
- No new shots.
- No reordering.
- No extra characters.
- Keep the product appearance completely unchanged, camera movement only, no rotation.
- Do not distort face, hands, logo, product shape, price text, or brand colors.
- If text is needed, leave clean space for editor-added captions.
```

## 13. Storyboard-first 成本控管

正式進 Seedance 2.0 或其他影片生成 AI 前，必須完成：

- [ ] 分鏡 grid 已確認

- [ ] 每格只有一個主要動作
- [ ] 影片比例與平台已確認
- [ ] 字卡、Logo、價格是否由剪輯後製疊上已確認
