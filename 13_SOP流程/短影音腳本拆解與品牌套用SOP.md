# 短影音腳本拆解與品牌套用 SOP

## 目的

把外部優秀影片拆解成可重複使用的內容架構，再套用到 Ewalk.ai 客戶的品牌、服務、受眾與轉換目標。

拆解完成後，必須把內容轉成「影片 AI 分鏡腳本包」，讓後續可以餵給 GPT Image 2 / Images 2.0、Seedance 2.0、其他影片生成 AI、設計企劃或剪輯師使用。

## 使用時機

- 提姆先生提供 YouTube、Reels、TikTok、廣告影片，覺得腳本值得學習時
- 客戶需要新的 Reels 企劃、廣告短片、活動前導影片時
- 社群主編需要把外部案例轉成品牌可拍攝腳本時
- 需要把影片腳本轉成 AI 影片生成 brief、Images 2.0 分鏡圖或 Seedance 2.0 動態生成 prompt 時

## 負責角色

- 阿順：判斷是否值得沉澱、分派任務、整合成果
- 影片腳本拆解員：拆段落、抽骨架、標註可複用機制
- 社群主編：轉成內容月曆與 Reels 企劃
- 設計企劃：補視覺、分鏡、拍攝需求
- 客戶成功經理：確認是否符合客戶目標與限制

## 輸入資料

- 影片連結或影片檔
- 客戶品牌資料
- 受眾、活動、服務主軸
- 預計輸出格式：Reels、廣告短片、限動、貼文、簡報

## 標準素材包

若工具與權限允許，拆解前先建立：

```text
metadata.json：影片標題、作者、日期、長度、描述、縮圖
captions.vtt / captions.srt：官方字幕或可取得字幕
transcript.md：自動轉錄或人工整理逐字稿
scenes.csv：場景起訖時間
keyframes/：每段代表畫面
notes.md：研究員觀察與資料限制
```

## 執行步驟

### 1. 來源確認

記錄：

- 標題
- 作者 / 頻道
- URL
- 發布日期
- 影片長度
- 是否取得逐字稿
- 是否有外部報導或 campaign 資料

若沒有逐字稿，只能做「架構拆解」，不能假裝有完整台詞。

### 2. 拆段落功能

每個段落至少標註：

| 段落 | 秒數 | 表面內容 | 真正功能 | 可複用原理 |
| --- | --- | --- | --- | --- |
| 1 | 0-3 秒 |  | 破題 / 鉤子 |  |
| 2 | 3-8 秒 |  | 情境建立 |  |
| 3 | 8-15 秒 |  | 痛點放大 |  |
| 4 | 15-25 秒 |  | 反轉 / 解法 |  |
| 5 | 25 秒後 |  | CTA / 記憶點 |  |

### 3. 做三層拆解

- 文字層：台詞、字幕、旁白、CTA、產品露出語句。
- 視覺層：場景、鏡頭、人物動作、字幕卡、道具、品牌露出。
- 節奏層：鉤子、懸念、反轉、情緒高點、留言誘因、轉換時機。

### 4. 抽出腳本骨架

用這個格式輸出：

```text
鉤子：
情境：
衝突：
反差：
解法：
反轉：
CTA：
```

### 5. 套用到客戶品牌

轉換時必須改寫四件事：

- 人物：從原片角色改成客戶真實受眾
- 衝突：從原片事件改成客戶痛點
- 解法：從原片品牌改成客戶服務優勢
- CTA：從原片活動改成客戶實際轉換行為

### 6. 產出可拍攝版本

每支腳本至少包含：

- 1 秒鉤子
- 30 秒內段落
- 畫面建議
- 字幕重點
- 口播或對白
- CTA
- 拍攝素材需求

### 7. 產出影片 AI 分鏡腳本包

每次影片拆解完成後，最後必須補一份可餵給影片 AI 的分鏡腳本包。

使用模板：[[../模板/影片AI分鏡腳本包模板|影片AI分鏡腳本包模板]]

內容至少包含：

- 專案 metadata：片長、類型、平台、調性、CTA
- 角色設定：正面、側面、背面、臉部特寫、服裝、表情、動作特徵
- 核心場景概念圖：主視覺、場景、品牌 / 產品露出
- Sequence A / B / C：每段時間、功能、情緒、主要畫面
- Shot-by-shot 分鏡：時間、景別、畫面、動作、字幕、鏡頭運動、AI 生成提示
- 相機運動與節奏：0-3 秒、3-5 秒、5-10 秒、10 秒後的剪輯目的
- 光線與色彩：主光、逆光、色票、品牌色
- 攝影 / 生成參數：比例、焦段、景深、幀率、色彩模式
- 影片生成 AI Prompt
- GPT Image 2 / Images 2.0 分鏡圖生成 Prompt
- Seedance 2.0 動態生成 Prompt

分鏡圖生成規則：

- 分鏡開發板、角色表、產品圖或 storyboard grid 由 GPT Image 2 / Images 2.0 生成。
- Images 2.0 prompt 必須先由文字分鏡腳本包產生，不可直接拿拆解摘要生成圖片。
- 生成圖用途是「內部視覺開發板」，不是對外發布圖。
- 小字、表格與 Logo 需要人工校稿，不可直接當正式交付物。

Storyboard grid 規則：

- 15 秒影片可用 4-5 格、8 格橫向或 3x3 grid。
- 30 秒影片可用 8-10 格、3x3 或 3x4 grid。
- 60 秒影片可用 15-18 格、4x4 grid，或拆段生成後剪輯。
- 產品、開箱、教學、染髮流程等影片，建議用 2 秒一段的 timestamp shotlist。
- 每格只放一個主要動作，避免 Seedance 2.0 讀到混亂指令。

### 8. 產出 Seedance 2.0 動態生成 brief

若後續要使用 Seedance 2.0，分鏡腳本包必須額外補一段動態生成 prompt。

輸入 reference：

- `@storyboard_grid`：已確認的單張分鏡宮格或視覺開發板
- `@character_sheet`：角色三視圖與臉部特寫
- `@product_reference`：產品、Logo、包裝、價目表或品牌素材

Prompt 必須包含：

- 影片長度、比例與平台
- `Follow the storyboard sequence of the reference frames in reading order`
- 鏡頭運動：慢推近、平移、俯拍、手持微晃、rack focus 等
- 一致性限制：角色長相、服裝、產品外觀、Logo、場景、品牌色
- 禁止事項：不要新增鏡頭、不要重排、不要新增角色、不要變形產品或價格文字

產品或品牌素材要加上：

```text
Keep the product appearance completely unchanged, camera movement only, no rotation.
```

### 9. Storyboard-first 成本控管

正式進影片生成前，阿順要確認：

- 分鏡圖已被確認，不再大改敘事順序。
- 角色、產品、Logo 與場景 reference 已確認。
- 價格、Logo、活動字卡是否改由剪輯後製疊上已確認。
- Seedance prompt 簡短、明確，沒有把所有企劃文字塞進去。
- 未取得授權的外部案例素材不進商用生成流程。

## 權限與風險

- 可以拆解公開影片的結構與方法。
- 不可大量複製原片台詞、分鏡、音樂或受版權保護素材。
- 不可把外部影片的明星、商標、素材直接放進客戶內容。
- 若要對外發布、投放廣告或使用外部素材，需提姆先生或客戶確認。
- 若使用 yt-dlp、Whisper、WhisperX、PySceneDetect、MoviePy 等工具，只能作為內部研究與素材分析；下載、剪輯或轉用第三方素材前需確認授權。
- 若使用 WhisperX 的 speaker diarization 或 Hugging Face 模型，需要先確認 token、授權與本機環境權限。
- 若參考 GitHub prompt repo，要先確認授權；EvoLinkAI README badge 與 LICENSE 檔授權標示不一致，Ewalk.ai 僅萃取方法，不直接複製外部素材或完整案例。

## 驗收標準

- 有清楚來源紀錄。
- 有段落功能拆解，不只是心得。
- 有清楚標註使用了哪些證據：字幕、逐字稿、場景表、代表畫面、報導或觀察。
- 有可複用腳本骨架。
- 有至少 1 支套用到客戶品牌的可拍攝腳本。
- 有影片 AI 分鏡腳本包，並清楚說明這份腳本是用來餵給 GPT Image 2 / Images 2.0 與 Seedance 2.0 / 影片生成 AI。
- 有標註資料缺口與待確認事項。
