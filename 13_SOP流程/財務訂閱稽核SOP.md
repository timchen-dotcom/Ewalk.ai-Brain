# 財務訂閱稽核 SOP

## 目的

建立 Ewalk.ai 的財務與訂閱稽核流程，定期整理每月工具訂閱、軟體費用與不必要支出，協助提姆先生控制公司營運成本。

## 使用時機

- 每月固定盤點訂閱費
- 提姆先生想知道 AI 工具、設計工具、雲端工具總花費
- 懷疑有重複訂閱或不必要訂閱
- 準備取消、降級或整併工具

## 權限前提

執行信箱稽核前，需要提姆先生授權信箱連接。

可讀資料：

- 訂閱通知信
- 發票
- 收據
- 付款成功通知
- 續約通知

不可自動做：

- 不可直接取消訂閱
- 不可更改付款方式
- 不可登入金融帳戶
- 不可對外聯繫客服
- 不可刪除信件

取消、降級、改付款設定，都必須先整理成提案，由提姆先生批准。

## 搜尋範圍

信箱搜尋關鍵字：

- subscription
- invoice
- receipt
- payment
- renewal
- paid
- billing
- 訂閱
- 發票
- 收據
- 付款
- 續約
- 扣款

優先工具類型：

- AI 工具：OpenAI、Anthropic、Google、Midjourney、Runway、ElevenLabs
- 設計工具：Adobe、Canva、Figma
- 自動化與雲端：Vercel、GitHub、Zapier、Make、Notion
- 行銷工具：Meta、Google Ads、EDM、CRM
- 儲存與協作：Google Workspace、Dropbox、iCloud

## 執行步驟

### 1. 收集本月訂閱紀錄

整理欄位：

| 欄位 | 說明 |
| --- | --- |
| 工具名稱 | 服務或廠商 |
| 金額 | 原幣別與換算台幣 |
| 週期 | 月繳 / 年繳 / 單次 |
| 扣款日期 | 信件或收據日期 |
| 用途 | 目前公司怎麼使用 |
| 使用者 | 提姆先生、阿順、團隊或客戶專案 |
| 狀態 | 建議保留 / 觀察 / 可取消 |
| 來源 | 信件標題、寄件者、連結或收據位置 |

### 2. 分類費用

分類：

- 必要營運工具
- 客戶交付工具
- AI 生產工具
- 設計與素材工具
- 自動化與雲端工具
- 重複或疑似閒置工具
- 待確認工具

### 3. 判斷保留或取消

保留條件：

- 正在支援客戶交付
- 已串進工作流
- 每週或每月穩定使用
- 取消會影響營運或交付

觀察條件：

- 偶爾使用
- 功能與其他工具重疊
- 金額偏高但仍可能有價值

取消或降級候選：

- 最近 30 天沒有用途
- 有重複功能
- 只是試用後忘記取消
- 年繳即將續約但沒有明確價值

### 4. 產出月訂閱稽核報告

報告格式：

```md
# YYYY-MM 訂閱費用稽核報告

## 本月總計

## 必要保留

## 建議觀察

## 建議取消 / 降級

## 待提姆先生確認

## 下月追蹤
```

### 5. 批准後執行

只有在提姆先生批准後，才能進入取消或降級流程。

執行前再次確認：

- 要取消的服務名稱
- 取消後影響
- 是否會刪除資料
- 是否有合約或年繳限制
- 是否需要先備份資料

## 建議排程

- 每月 3 日：整理上月訂閱費用
- 每月 5 日：提交保留 / 取消建議
- 每月 7 日：依提姆先生批准結果執行後續

## 驗收標準

- 已列出本月所有可辨識訂閱
- 已標註金額、用途、狀態與來源
- 已區分保留、觀察、取消候選
- 未經批准不做取消或金流操作
- 已整理下月追蹤清單
