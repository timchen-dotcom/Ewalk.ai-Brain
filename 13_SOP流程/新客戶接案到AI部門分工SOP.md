# 新客戶接案到 AI 部門分工 SOP

## 目的

當提姆先生接到新客戶或新需求時，阿順要能像公司專業經理人一樣，快速判斷要啟動哪些部門、安排哪些工作、建立哪些文件，並讓任務能每日、每週、每月持續執行。

## 使用時機

- 新客戶進入 Ewalk.ai
- 舊客戶新增合作項目
- 客戶提出社群、活動、廣告、月報、素材或自動化需求
- 提姆先生口頭交辦一個需要多人分工的專案

## 最小輸入

提姆先生只要先提供：

```text
客戶名稱：
產業 / 地區：
需求：
目前已知平台：
期限：
預算或限制：
```

如果資料不足，阿順先建立待補清單，不等待完整資料才開始。

## 標準流程

### 1. 阿順判斷任務類型

先分類：

- 社群經營
- 檔期活動
- 廣告投放
- 月報與數據
- 品牌策略
- 素材整理
- 自動化 / 系統串接
- 財務 / 訂閱稽核

### 2. 建立或更新客戶資料夾

必要文件：

- `00_客戶總覽.md`
- 客戶需求盤點
- 部門分工文件
- 第一階段工作節奏
- 待補資料清單

### 3. 分派部門

| 需求 | 啟動部門 | 主要產出 |
| --- | --- | --- |
| 客戶剛進來 | 客戶成功與策略部、專案管理部 | 需求盤點、合作範圍、時程 |
| IG / FB 經營 | 社群內容部、視覺設計部、數據報表部 | 內容支柱、內容月曆、成效追蹤 |
| Reels / 短影音 | 社群內容部、視覺設計部 | 腳本、分鏡、拍攝需求 |
| 檔期活動 | 客戶成功與策略部、社群內容部、廣告投放部 | 活動主軸、文案、廣告 Brief |
| 廣告投放 | 廣告投放部、數據報表部 | 受眾、素材、預算建議、優化節奏 |
| 月報 | 數據報表部、客戶成功與策略部 | 成效摘要、問題、下月建議 |
| 訂閱費用 | 財務與訂閱稽核部 | 訂閱清單、保留 / 取消建議 |
| 自動化 | AI 自動化與知識管理部 | SOP、Skill、工具串接規格 |

### 4. 建立工作節奏

#### 社群型客戶

- 每週一：確認本週內容主題與活動重點
- 每週二：完成文案、腳本、視覺需求
- 每週三：檢查素材與排程
- 每週四：廣告素材與活動檢查
- 每週五：整理成效與下週調整建議

#### 廣告型客戶

- 上線前：確認目標、受眾、預算、素材、追蹤
- 上線第 1 天：檢查投放是否正常
- 上線第 3 天：檢查 CTR、CPC、CPM
- 上線第 7 天：檢查轉換與 CPA
- 每月：整理廣告復盤

#### 月報型客戶

- 每月第 1 週：整理數據
- 每月第 2 週：產出月報初稿
- 每月第 2 週內：阿順整合建議
- 提交前：提姆先生確認重要策略與語氣

### 5. 阿順整合回報

回報格式：

```md
## 已啟動部門

## 第一週會做什麼

## 本月預計交付

## 缺少資料

## 需要提姆先生批准的事項
```

## TheVision 分工範例

需求：

- 淡水髮廊品牌
- 經營 IG / FB
- 檔期活動規劃
- 廣告投放

應啟動：

| 部門 | 角色 | 工作 |
| --- | --- | --- |
| 客戶成功與策略部 | 客戶成功經理、品牌策略企劃 | 釐清品牌定位、客群、服務主力、檔期目標 |
| 市場洞察部 | 美感趨勢研究員、競品研究員 | 研究淡水在地、美髮流行、髮廊社群內容 |
| 社群內容部 | 社群主編、文案企劃、Reels 腳本企劃 | 建立 IG / FB 內容支柱、月內容表、貼文與短影音腳本 |
| 視覺設計部 | 設計企劃、圖像 Prompt 工程師 | 建立視覺需求、素材清單、活動圖像方向 |
| 廣告投放部 | Meta 廣告投放專員 | 建立檔期活動廣告 Brief、受眾、素材、預算建議 |
| 數據報表部 | 數據分析師 | 建立週成效追蹤與月報格式 |
| 專案管理部 | 專案助理 | 排週工作、追待辦、整理回報 |

## 權限規則

阿順可以直接做：

- 建立工作文件
- 分派內部 AI 角色
- 產出策略、文案、腳本、Brief、報告草稿
- 建議每日、每週、每月工作節奏

需要提姆先生批准：

- 對客戶正式承諾交付項目
- 上線廣告或調整實際預算
- 對外發送正式訊息
- 修改報價、合約、付款、取消訂閱

## 驗收標準

- 客戶資料夾已建立或更新
- 已明確分派部門
- 已建立第一週工作清單
- 已列出待補資料
- 已標註需要提姆先生批准的事項
- 已定義每週 / 每月回報節奏
