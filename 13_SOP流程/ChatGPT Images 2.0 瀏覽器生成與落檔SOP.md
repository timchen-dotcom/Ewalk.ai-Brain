# ChatGPT Images 2.0 瀏覽器生成與落檔 SOP（手動版）

## 目的

在「無法由阿順直接調用 Images 2.0 API/工具」的情況下，仍能把圖片生成納入交付流程：

- 先由阿順輸出可用的 Images 2.0 Prompt
- 再由人類在瀏覽器（ChatGPT）內生成
- 下載後落到指定客戶資料夾，方便後續套版與交付

## 適用時機

- 要做 IG 貼文/廣告圖/限動，但缺少實拍素材
- 想先用生成圖做版型草稿，再等實拍替換
- 需要快速做「同風格多版本」素材變體

## 重要原則（避免風險）

- **不要假裝生成圖是實拍**：若貼文會被當成實際出餐照片，需標註為示意，或改成「版型草稿」內部使用。
- **不要輸入客戶機密**：例如未公開的店址、電話、內部價格策略、未發布活動。
- **圖上文字不要用生成**：文字請在 Open Design/設計工具中排版，避免字體錯誤與可讀性問題。

## 執行步驟（最小可行）

### 1) 從阿順拿到三件輸出

阿順需提供：

1. 設計需求稿（尺寸、版面、必放元素、禁忌）
2. Open Design Prompt（用來做可重跑的版型）
3. Images 2.0 Prompt（只負責生成「主視覺圖片」，不含文字）

### 2) 在瀏覽器登入 ChatGPT

- 你只要用自己的瀏覽器登入 ChatGPT 即可
- **不需要也不建議**提供任何帳密或「授權給阿順」的動作

> 若要讓阿順代操作，需要啟用可用的瀏覽器/桌面自動化權限；這依環境政策可能被禁用。

### 3) 生成圖片（Images 2.0）

1. 開啟 ChatGPT
2. 選擇可生成圖片的模型/模式（Images 2.0）
3. 貼上「Images 2.0 Prompt」
4. 生成後選最好的 1–3 張（先求可用、再求完美）

### 4) 下載與命名

命名格式（建議統一）：

```text
YYYY-MM-DD_客戶_用途_品項_尺寸_v1.png
```

例如：

```text
2026-05-07_韓食日常鍋物_IG_馬鈴薯排骨湯_1080x1350_v1.png
```

### 5) 落檔到客戶資料夾

建議落檔位置（擇一，保持一致）：

- 客戶素材集中：`Ewalk.ai Brain/01_客戶/韓食日常鍋物/04_素材/Images2/`
- 單次內容交付：`Ewalk.ai Brain/01_客戶/韓食日常鍋物/02_活動與內容/`

### 6) 套版產出最終貼文圖

- 用 Open Design 先產出可重跑版型（HTML）
- 把生成圖置入主視覺框（或以 CSS 背景圖方式置入）
- 文字、價格、CTA 都由版型排版（不要依賴生成圖上的文字）

## 驗收標準（自我檢查）

- 圖片符合品牌風格（現代、乾淨、高對比），沒有老派韓流元素
- 食物看起來可信、可口，但不誇張到像假圖
- 圖內沒有亂碼文字、怪字、錯字
- 落檔路徑正確、命名一致，方便下次找得到
