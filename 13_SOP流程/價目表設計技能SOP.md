# 價目表設計技能 SOP

## 目的

把客戶零散的價目表、服務內容、品牌規範與參考版型，轉成可交付的 A4 / A5 / 社群尺寸價目表。此技能給「設計企劃」使用，負責建立清楚的資訊架構、image2 視覺 Prompt、正式落檔與驗收標準。

## 使用時機

- 客戶提供舊價目表截圖、圖片、PDF 或手寫價格資料。
- 客戶想把多張價目表整理成一張清楚菜單。
- 需要依品牌 CIS 做 A4 海報、DM、LINE 圖文、IG 輪播或店內展示圖。
- 使用者提供喜歡的參考版型，要求保留其資訊節奏但改成客戶品牌調性。

## 負責角色

- 主責：設計企劃
- 協作：阿順整理資訊架構與把關
- 最終確認：提姆先生或客戶窗口

## 輸入資料

設計企劃開始前要先確認：

- 客戶名稱與品牌資料夾位置
- 價目表原始資料：圖片、PDF、Excel、文字、官網截圖
- 品牌規範：Logo、色票、字體、視覺禁忌、語氣
- 參考版型：使用者喜歡的價目表、菜單或 DM
- 必放資訊：課程名稱、價格、會員價、加購項目、注意事項
- 是否包含 QR、電話、地址、LINE、IG 等店家資訊
- 輸出尺寸：A4、A5、1080x1350、LINE 圖文選單等

## 核心原則

### 1. 先做資訊設計，不先做美術

價目表的第一目標是讓客人快速理解：

- 有哪些分類
- 每個分類有哪些服務
- 服務差異是什麼
- 原價與會員價是多少
- 加購項目怎麼搭配

若分類超過 5 類，優先重新合併。A4 價目表建議控制在 3 到 4 個主要分類。

### 2. 分類要用客人看得懂的語言

不要直接照內部品項亂排。分類名稱要能描述需求情境。

範例：

```text
頭皮養護紓壓
臉部深層清潔護理
頭皮養護＋臉部護理
```

### 3. image2 負責視覺質感，不負責文字正確性

image2 可用來做：

- 整體視覺
- 背景質感
- 版面風格
- 卡片節奏
- 圖示與裝飾

image2 不應被當成唯一正字工具。正式交付前必須檢查：

- 課程名稱
- 價格
- 會員價
- 加購項目
- 注意事項
- QR code 是否可掃

### 4. QR code 絕對不要交給 image2 重畫

若價目表或海報需要 QR：

1. image2 只生成「白色 QR 佔位框」。
2. 後製時貼上客戶提供的官方 QR 原檔。
3. QR 不做柔焦、不透明度、不加遮罩、不套濾鏡。
4. 輸出後用手機實掃；若無法實掃，至少保留官方 QR source 檔供人工驗證。

## 標準流程

### 1. 讀取客戶資料

先讀：

- `01_品牌資料/品牌資料總覽.md`
- `01_品牌資料/品牌規範.md`
- `04_素材/品牌識別/`
- 既有價目表整理文件或原始素材

若沒有品牌規範，先回報「品牌資料不足」，不要自行發明品牌色與 Logo。

### 2. 整理價目表內容

建立一份文字版價目表，放在客戶 `01_品牌資料` 或 `03_提案與交付`。

內容至少包含：

- 用途
- 使用時機
- 價目總覽
- 分類式價目表
- 加購項目
- 待確認事項

### 3. 建立版面策略

依用途選版型：

| 用途 | 建議版型 |
| --- | --- |
| 店內展示 A4 | 上方品牌區，中段服務卡片，下方加購表格 |
| LINE 圖文選單 | 少字、大按鈕、3 到 4 個入口 |
| IG 輪播 | 第一頁分類總覽，後續每頁一類 |
| 官網服務頁 | 分類卡片＋完整流程＋FAQ |

### 4. 產出 image2 Prompt

使用：[[../11_Prompt資料庫/價目表設計Image2Prompt|價目表設計 Image2 Prompt]]

Prompt 必須包含：

- 尺寸與比例
- 品牌 CIS
- 參考版型要保留哪些東西
- 明確分類
- 完整且精簡的文字
- 價格
- 禁止事項
- 若有 QR：要求 image2 留白框，不生成 QR

### 5. 生成 image2 視覺

最少產出 1 張，重要客戶建議產出 2 到 3 張。

選圖標準：

- 第一眼是否清楚
- 是否像該品牌
- 是否有足夠留白
- 價格是否容易比較
- 分類是否直覺
- 是否不像促銷單、傳單或廉價菜單

### 6. 後製與正字

若 image2 文字錯誤或價格錯誤：

- 不能假裝沒問題。
- 可用正字排版版重做文字。
- 若使用者要求最終視覺必須 image2，需回報 image2 版本是視覺成品，但正式對外前仍應人工校字。

若含 QR：

- 以官方 QR 原檔疊入。
- 檔案命名保留 `QR_source`。
- 輸出 PNG / PDF 後實掃確認。

### 7. 落檔

建議資料夾：

```text
Ewalk.ai Brain/01_客戶/{客戶名稱}/03_提案與交付/{用途}_{日期}/
```

建議檔名：

```text
{客戶}_服務價目表_A4_image2視覺初稿_{YYYYMMDD}.png
{客戶}_服務價目表_A4_image2最終版_{YYYYMMDD}.png
{客戶}_服務價目表_A4_正字版_{YYYYMMDD}.png
{客戶}_服務價目表_A4_正字版_{YYYYMMDD}.pdf
image2_prompt_{用途}_{YYYYMMDD}.md
```

## 驗收標準

設計企劃交付前必須檢查：

- [ ] 分類不超過 5 類，且客人看得懂。
- [ ] 每個服務都有名稱、重點、原價、會員價或價格。
- [ ] 價格與原始資料一致。
- [ ] 加購項目與主服務分類邏輯一致。
- [ ] 版面符合品牌 CIS。
- [ ] 沒有醫療療效、保證效果或誇大字眼。
- [ ] 字體清楚，沒有亂碼、錯字、破字。
- [ ] QR 沒有被 image2 重畫，且可掃。
- [ ] 檔案已落到客戶資料夾。
- [ ] 已保留 image2 Prompt，方便重跑。

## STAR SPA 實戰範例


```text
這張參考圖我喜歡它的資訊節奏，請保留版面邏輯，但不要照抄視覺風格；請轉成客戶 CIS，並輸出 image2 Prompt 與正式落檔檢查清單。
```

```text
這張海報需要 QR。請 image2 只做底圖與 QR 佔位框，最後用官方 QR 原檔後製疊上，並確認輸出檔案可掃。
```
