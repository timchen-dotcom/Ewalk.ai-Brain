# 美感趨勢週報

這裡存放 Ewalk.ai 每週五產出的美感趨勢週報，主題聚焦台灣與華語圈常見的線上雜誌、媒體平台與 Google News。

## 四大面向

- 美髮
- 美妝
- 時尚
- 潮流

## 核心目的

幫提姆快速掌握一週內台灣市場正在被討論的美感趨勢，轉化成 Ewalk.ai 可用的內容企劃、客戶提案、素材方向與廣告洞察。

## 使用規則

- 保留所有來源連結。
- 不搬運全文，只保存標題、來源、連結、摘要與趨勢判讀。
- 每日可做輕量收集，但每週五才產出正式週報。
- 週報要用白話說明「這對 Ewalk.ai / 客戶有什麼用」。
- 若某個趨勢可轉成內容、廣告、Reels、素材或提案，需標註可行動建議。

## 檔案結構

- `每日收集/`：每日文章連結與初步摘要
- `週報/`：每週五正式趨勢週報
- `來源清單.md`：追蹤來源與查詢策略

## 週報命名

```text
YYYY-MM-DD_美感趨勢週報.md
```

## 建議閱讀方式

先看「本週三個重點」，再看四大面向，最後看「可用於 Ewalk.ai 的行動建議」。
