# 命名規範

## 日期格式

統一使用：

```text
YYYY-MM-DD
```

月報使用：

```text
YYYY-MM
```

## 常用命名

| 類型 | 命名格式 |
| --- | --- |
| 客戶總覽 | `00_客戶總覽.md` |
| IG 內容 | `YYYY-MM-DD - IG - 主題.md` |
| Reels | `YYYY-MM-DD - Reels - 主題.md` |
| 廣告 | `YYYY-MM-DD - 廣告 - 活動名稱.md` |
| 月報 | `YYYY-MM - 客戶名稱 - 月報.md` |
| 會議紀錄 | `YYYY-MM-DD - 會議 - 客戶名稱 - 主題.md` |
| 語音筆記 | `YYYY-MM-DD - 語音 - 主題.md` |
| 案例 | `YYYY-MM-DD - 案例 - 客戶名稱 - 主題.md` |
| SOP | `動作名稱SOP.md` |
| Prompt | `用途Prompt.md` |

## 資料夾命名

- 數字排序使用兩位數：`00_`、`01_`
- 中文名稱優先
- 客戶名稱保留品牌原始名稱
- 不使用特殊符號作為檔名分隔，避免同步問題

## 版本命名

若需要保留版本：

```text
檔名_v1.md
檔名_v2.md
檔名_final.md
```

正式交付前，建議在總覽頁標記目前採用版本。
