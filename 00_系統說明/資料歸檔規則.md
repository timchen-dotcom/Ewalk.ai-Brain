# 資料歸檔規則

## 快速判斷

| 內容 | 放哪裡 |
| --- | --- |
| 未整理資料 | `00_收件匣` |
| 語音逐字稿 | `00_收件匣/語音轉錄` |
| 客戶品牌資料 | `01_客戶/客戶名稱/01_品牌資料` |
| 客戶活動內容 | `01_客戶/客戶名稱/02_活動與內容` |
| 客戶提案交付 | `01_客戶/客戶名稱/03_提案與交付` |
| 客戶素材 | `01_客戶/客戶名稱/04_素材` |
| 一般 IG 內容模板 | `02_內容/IG內容` |
| 一般 Reels 模板 | `02_內容/短影音Reels` |
| 廣告策略與投放 | `03_廣告` |
| 月報 | `04_報表/月報` |
| 策略框架 | `05_策略` |
| 共用素材 | `06_素材` |
| 會議紀錄 | `07_會議` |
| 自動化設定 | `08_自動化` |
| 可複用知識 | `09_知識庫` |
| 市場與產業洞察 | `10_市場洞察` |
| AI Prompt | `11_Prompt資料庫` |
| 成功與失敗案例 | `12_案例庫` |
| 標準流程 | `13_SOP流程` |
| 不再使用資料 | `99_封存` |

## 原則

- 有客戶歸屬的資料優先放客戶資料夾
- 有跨客戶價值的洞察要抽到知識庫或案例庫
- Prompt 不放在客戶資料夾，除非是該客戶專用 Prompt
- 會議結論若產生 SOP，要另存到 `13_SOP流程`
