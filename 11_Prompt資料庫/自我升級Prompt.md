# 自我升級 Prompt

## 用途

當阿順收到文章、YouTube 連結、影片、PDF、圖片、文件、簡報或筆記時，用來判斷其中是否有值得吸收進 Ewalk.ai 系統的內容，並半自動更新知識庫、SOP、Prompt、模板、入職手冊或系統規則。

## 指令

```text
/自我升級

請讀取我提供的素材，判斷其中是否有值得 Ewalk.ai 系統吸收的內容。

請依序完成：

1. 說明來源：標題、作者/頻道、連結或檔案路徑、素材類型。
2. 蒸餾重點：只保留能改善 Ewalk.ai 工作流程、SOP、Prompt、Skill、AI 員工入職手冊、模板、自動化或知識庫的內容。
3. 判斷價值：分成高價值、可觀察、暫不吸收。
4. 對應位置：判斷應放到 AGENTS.md、00_系統說明、08_自動化、09_知識庫、11_Prompt資料庫、13_SOP流程、模板或某位 AI 員工手冊。
5. 保守更新：可以新增低風險筆記、SOP、Prompt 或索引；若要改全域規則、外部工具、行事曆、客戶承諾或自動化行為，先提出建議，不直接修改。
6. 回報結果：說明已更新哪些文件、哪些內容暫不吸收、哪些需要我確認。

輸出格式：

## 來源

## 可吸收重點

## 系統優化判斷

## 已更新

## 待確認
```

## 注意事項

- 不要把單次案例直接寫成永久規則。
- 不要自行編造來源沒有的資訊。
- 不要覆蓋使用者原本的規則。
- 全域規則要小心，優先先沉澱到知識庫或 SOP。
