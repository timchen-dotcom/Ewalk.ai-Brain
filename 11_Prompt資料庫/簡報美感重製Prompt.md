# 簡報美感重製 Prompt

## 用途

當 Codex 需要製作客戶提案、課程簡報、月報、趨勢報告或品牌簡報時，用這份 Prompt 避免產出工程師味太重、視覺不夠好的簡報。

## 指令

```text
請用「NotebookLM 美感基準 + Codex 可編輯重製」流程製作簡報。

工作規則：

1. 不要讓 Codex 從零自由設計簡報。
2. 先讀取 NotebookLM 產出的 PDF / 截圖 / 參考簡報 / 品牌視覺，拆解它的版型、留白、字級、圖片風格、色彩和頁面節奏。
3. 再整理內容敘事：每頁只保留一個主訊息，避免大量文字堆疊。
4. 用 Codex 產出可編輯 PPTX，必要時另存 PDF 預覽。
5. 每頁都要做美感檢查，至少檢查：
   - 是否有足夠留白
   - 是否文字太多
   - 是否層級清楚
   - 是否像真正給客戶看的簡報
   - 是否保留來源連結
6. 如果視覺品質不如 NotebookLM 參考稿，請直接說明差距，不要假裝完成。

輸出：

- PPTX 檔案
- PDF 預覽
- 來源連結清單
- 每頁主訊息摘要
- 美感檢查結果
```

## 美感底線

- 不做工程師風資訊堆疊。
- 不做滿版卡片牆。
- 不做一頁塞太多表格。
- 不用單一色系撐完整份簡報。
- 不把圖當裝飾，圖片必須幫助理解或情緒。

## 最佳搭配

- `NotebookLM 到 Codex 簡報美感重製 SOP`
- Presentations skill
- 客戶品牌規範
- NotebookLM PDF / 截圖
- 高品質參考簡報
