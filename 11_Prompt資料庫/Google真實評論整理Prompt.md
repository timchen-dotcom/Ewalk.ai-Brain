# Google 真實評論整理 Prompt

## 用途

用於門市現場的評論輔助工具，協助真實消費者把服務體驗整理成自然、具體、可自行修改的 Google 評論草稿。

## 使用時機

- 顧客完成服務後，不知道如何描述體驗。
- 店家希望評論自然補足服務項目、地區、品牌與服務人員資訊。
- 工具需要用 LLM 產出多個語氣版本，但必須避免不實評論與過度 SEO 化。

## 輸入

```json
{
  "brand_name": "品牌名稱",
  "store_area": "所在地區",
  "service_item": "服務項目",
  "staff_name": "服務人員或設計師",
  "customer_feelings": ["顧客實際勾選的感受"],
  "customer_note": "顧客自己補充的一句真實經驗",
  "tone": "natural | specific | warm",
  "target_length": "80 | 100 | 120"
}
```

## 處理原則

- 只整理使用者提供的真實資訊，不得自行捏造服務細節。
- 不保證五星，不暗示一定要正評。
- 可以自然帶到品牌、地區、服務項目與服務人員，但不要每句都塞關鍵字。
- 若 `customer_feelings` 與 `customer_note` 都是空的，請要求使用者補充，不要直接生成。
- 文字要像一般消費者分享，不要像廣告文案、SEO 文章或官方推薦文。
- 每次可產生不同說法，但差異應來自語氣、句構與使用者真實細節，不是為了規避平台偵測。

## 輸出格式

```json
{
  "drafts": [
    {
      "label": "自然版",
      "text": "評論草稿",
      "check_note": "提醒顧客確認是否符合實際體驗"
    }
  ],
  "safety_check": {
    "uses_only_customer_input": true,
    "has_fake_detail": false,
    "is_over_optimized": false
  }
}
```

## 驗證標準

- 草稿約 80 到 120 字，除非使用者指定其他長度。
- 至少包含服務項目或顧客實際感受。
- 不得出現「最強」「第一名」「保證」「必來」等過度宣稱。
- 不得創造使用者未提供的價格、折扣、等待時間、療效或前後對比。
- 顧客可以直接修改、刪減或不用。
