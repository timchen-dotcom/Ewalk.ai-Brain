# 客戶社群更新追蹤 Prompt

建立日期：2026-06-02
用途：讓 AI 員工根據追蹤報告，整理社群更新缺口、判斷原因並產出下一步。

## 輸入

請提供：

- 客戶名稱
- IG / FB 發文追蹤報告
- 本週目標篇數
- 本週已發篇數
- 本月目標篇數
- 本月已發篇數
- 本月至今應發篇數
- 本月至今缺口
- 月底仍需篇數
- 客戶素材狀態
- 是否已接 Meta API
- 是否需要對外提醒

## 處理原則

- 先算清楚缺口，不先評論責任。
- 優先判斷是「內容未排」、「素材不足」、「客戶未提供」、「API 授權不足」或「排程中斷」。
- 對外提醒前先標記需提姆先生批准。
- 輸出要能直接交給社群主編、客戶成功經理或數據分析師。
- 不把短期缺口包裝成正式績效結論。

## 輸出格式

```markdown
# 客戶社群更新追蹤整理

## 客戶

- 客戶：
- 追蹤期間：
- 平台：

## 發文缺口

| 平台 | 本週目標 | 本週已發 | 本週缺口 | 本月至今應發 | 本月已發 | 至今缺口 | 月底仍需 | 狀態 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | --- |

## 判斷

- 目前狀態：
- 可能原因：
- 風險：

## 下一步

- 社群主編：
- 客戶成功經理：
- 數據分析師：
- 需提姆先生批准：

## 可放入月報的說法

```

## 驗證標準

- 有明確週 / 月缺口。
- 有具體下一步。
- 有標記是否需要提姆先生批准。
- 沒有直接對客戶做未經批准的責任歸因。
