# Google 評論回覆追蹤 Prompt

## 用途

將 Google 評論每日追蹤系統抓到的未回覆評論，整理成可人工審核的回覆草稿與處理建議。

## 使用時機

- 每日報表出現新增評論。
- 未回覆評論即將到期或已逾期。
- 客戶成功經理需要快速產出多則評論回覆草稿。
- 負評需要先整理風險與回覆方向。

## 輸入

請提供：

```md
客戶名稱：
品牌名稱：
分店名稱：
評論星等：
評論者：
評論日期：
回覆到期日：
評論內容：
設計師 / 服務人員：
服務項目：
品牌語氣：
品牌回覆範本：
是否高風險：
注意事項：
```

## 處理原則

1. 不捏造評論者沒有提到的服務細節。
2. 不承諾退款、補償、療效、法律責任或未授權事項。
3. 正評回覆要自然感謝，避免罐頭感。
4. 中性評論要承認體驗、表達重視，必要時提供可聯繫方式。
5. 負評先同理，再引導私訊或客服處理，不公開爭辯。
6. 涉及醫療、法律、金流、歧視、個資、消費爭議時，標註「需提姆先生或客戶確認」。
7. 回覆草稿只供人工審稿，不可直接自動送出。
8. 若有提供品牌回覆範本，優先模仿句型節奏與溫度，但不得複製成完全相同的罐頭文字。
9. 若有設計師 / 服務人員，需自然提及，不要讓回覆變成硬塞名字。
10. 美髮類正評可補一句居家保養或定期整理提醒，但不得誇大修復、保證效果。

## 輸出格式

```md
## 判斷

- 風險等級：
- 建議處理期限：
- 是否需要提姆先生 / 客戶確認：
- 原因：

## 回覆草稿 A｜正式穩健

（草稿）

## 回覆草稿 B｜溫暖親切

（草稿）

## 回覆草稿 C｜品牌長版

（草稿）

## 內部備註

- 需要補問客戶的事：
- 不建議寫的內容：
- 後續追蹤：
```

## 驗證標準

- 回覆內容有對應評論重點。
- 沒有虛構服務、承諾或敏感資訊。
- 客戶可直接審稿修改。
- 高風險評論有明確升級提醒。
