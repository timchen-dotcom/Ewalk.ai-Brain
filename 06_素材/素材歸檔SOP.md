# 素材歸檔 SOP

## 收到素材時

1. 判斷素材屬於哪個客戶
2. 放進 Google Drive 對應客戶資料夾
3. 若尚未分類，先放 `00_客戶提供`
4. 重要素材在 Obsidian 客戶總覽補連結

## 製作素材時

1. 原始檔放 `原始素材` 或 `素材原檔`
2. 輸出版放 `上線版本` 或 `確認版`
3. 廣告素材要記錄 A/B 測試版本
4. 交付給客戶的檔案放 `05_交付檔案`

## 上線後

1. 在 Obsidian 對應內容筆記補上素材連結
2. 廣告素材同步記錄到 `03_廣告`
3. 成效好的素材整理到 `12_案例庫`
4. 不再使用的素材移到 `99_封存`

## 每月整理

- [ ] 檢查客戶資料夾是否有未分類素材
- [ ] 將上線素材與原始素材分開
- [ ] 將客戶確認版集中到 `05_交付檔案`
- [ ] 把成功素材整理成案例
- [ ] 封存過期活動素材
