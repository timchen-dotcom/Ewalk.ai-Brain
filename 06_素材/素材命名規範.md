# 素材命名規範

## 基本格式

```text
YYYY-MM-DD_客戶名稱_用途_主題_版本
```

範例：

```text
2026-04-27_STARSPA_Reels_頭皮養護_v1.mp4
2026-04-27_TheVision_IG_三倍水光染_v2.png
2026-04-27_TGhair_Ads_夏季活動_A.jpg
```

## 常用用途

| 用途 | 說明 |
| --- | --- |
| Logo | Logo 與品牌識別 |
| Brand | 品牌規範與視覺系統 |
| IG | IG 貼文素材 |
| Reels | 短影音素材 |
| Story | 限動素材 |
| Ads | 廣告素材 |
| Report | 月報素材 |
| Proposal | 提案素材 |
| Raw | 原始檔 |
| Final | 確認版 |

## 版本規則

- `v1`：第一版
- `v2`：第二版
- `final`：客戶確認版
- `published`：實際上線版
- `archive`：不再使用但需保留

## 注意事項

- 檔名不要只寫 `final`，要保留日期與用途
- 不使用特殊符號作為分隔，建議用 `_`
- 客戶名稱固定寫法，避免同一客戶出現多種拼法
- 可公開素材與客戶內部素材要分開存放
