# 美業多分店訂購系統

建立日期：2026-05-24
狀態：需求整理中
負責整合：阿順
決策把關：提姆先生

## 目的

建立一套以網站作為入口的內部訂購系統，讓美業品牌或多分店客戶可以管理各分店的洗護、染膏、藥水與耗材訂單。

系統核心不是一般電商，而是「分店下單、總部統整、管理者彙整採購」的營運工具。

## 使用時機

- 客戶有多家分店，需要統一收集內部產品訂購需求。
- 分店需要快速填寫品牌、品項、規格、價格與數量。
- 管理者需要看到每一間分店的訂單，也要能彙總成採購表。
- Ewalk.ai 需要把這類營運系統包裝成可複製的 AI 行銷整合服務。
