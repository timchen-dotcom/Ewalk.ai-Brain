# 網站發佈佇列

## 用途

集中追蹤 Ewalk.ai 所有待發佈、已發佈與需要審核的網站專案，避免每次上線都重新找路徑、重新判斷風險、重新整理部署資訊。

## 狀態規則

- `草稿`：仍在 Vault 或原型階段，不部署。
- `Preview 可部署`：可用固定腳本發佈測試網址。
- `Preview 已發佈`：已有 Vercel Preview URL。
- `Production 待批准`：準備正式公開，但需提姆先生確認。
- `Production 已發佈`：正式網址已上線。

## 發佈清單

| 專案 | 類型 | 狀態 | 發佈工作區 | Vercel 專案 | Preview URL | Production URL | 風險 | 備註 |
|---|---|---|---|---|---|---|---|---|
| Google 真實評論整理小幫手 | 內部工具 / 客戶工具 | Production 已發佈 | `sites/ewalk-tools/google-review-helper` | `ewalk-tools-google-review-helper` | Preview 受 Vercel Protection 保護 | `https://ewalk-tools-google-review-helper.vercel.app` | 低 | 靜態工具，不含個資、金流與 API key |

## 快速部署指令

```bash
./deploy-site-preview.command ewalk-tools/google-review-helper
```

## 自動部署指令

```bash
./auto-deploy-sites.command
```

自動部署設定來源：

```text
sites/deploy.config.json
```

## Production 前檢查

- [ ] 網站內容無客戶未確認承諾。
- [ ] 無個資、金流、API key 或內部機密。
- [ ] Google 評論連結、QR Code 與品牌資訊正確。
- [ ] 已用手機掃描測試主要流程。
- [ ] 若掛正式網域，已由提姆先生批准。
