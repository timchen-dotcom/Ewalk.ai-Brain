# 客戶檔期上線標準流程

建立日期：2026-05-05

## 核心規範

每個客戶檔期每次設計完，都要同步執行以下三大通路：

1. LINE OA
2. IG / FB 社群
3. Google 商家

## LINE OA

- [ ] 圖文選單
- [ ] 自動化訊息
- [ ] 歡迎訊息
- [ ] 群發設定
- [ ] 熟客積點 / 會員機制（若該檔期需要）

## IG / FB 社群

- [ ] 主貼文
- [ ] 置頂貼文
- [ ] 限動
- [ ] Reels / 短影音（若有）
- [ ] 粉專同步

## Google 商家

- [ ] 活動檔期貼文
- [ ] 服務或優惠資訊
- [ ] 圖片素材
- [ ] 預約連結 / 聯絡方式

## 檢查點

- [ ] 文案一致
- [ ] 活動日期一致
- [ ] 價格與優惠一致
- [ ] QR / 預約連結正確
- [ ] 每個平台皆已上架
