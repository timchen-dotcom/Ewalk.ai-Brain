# 0520 現場語音阿順彩排檢查清單

## 啟動前

- [ ] OpenAI API key 已填入 `realtime-demo/.env.local`
- [ ] 確認帳號可使用 `gpt-realtime-2`
- [ ] 確認當天網路：主網路 + 手機熱點備援
- [ ] 確認麥克風輸入正常
- [ ] 確認現場喇叭 / 音響輸出正常
- [ ] 瀏覽器可開啟 `http://127.0.0.1:4320`

## Demo 功能

- [ ] 可以按「開始語音阿順」
- [ ] 瀏覽器有要求麥克風權限
- [ ] 阿順能聽到主持人問題
- [ ] 阿順能語音回答
- [ ] 聲音偏成熟穩重男性顧問感，不像大陸腔女生
- [ ] 語氣是台灣繁中口吻，避免大陸用語
- [ ] 語速約 1.3 倍，但咬字清楚
- [ ] 回答控制在 10-18 秒，最多 3 句話
- [ ] 回答像現場對話，不像背簡報稿
- [ ] 文字備援可查核心知識
- [ ] 預設 Q&A 備援可播放系統語音

## 必測問題

- [ ] 什麼是一個人的經濟？
- [ ] Ewalk.ai 行銷大腦能幫加盟店做什麼？
- [ ] STAR Color 跟一般染髮加盟有什麼不同？
- [ ] 幻色鏡方為什麼需要 AI 大腦？
- [ ] 5/20 現場最重要要讓大家記住什麼？

## 現場備援

- [ ] 若 GPT-Realtime-2 無法啟動，改用文字備援
- [ ] 若網路不穩，改用預設 Q&A
- [ ] 若麥克風收音差，由主持人打字
- [ ] 若阿順回答偏離，主持人拉回五個核心問題
- [ ] 若全部失效，使用預錄語音或主持人照稿

## 驗收標準

- 阿順不是要回答所有問題，而是要讓現場相信：Ewalk.ai 能成為 STAR Color 與幻色鏡方的 AI 大腦。
- 回答寧可短、穩、準，不要長、炫、散。
- 現場效果優先於技術完整度。
