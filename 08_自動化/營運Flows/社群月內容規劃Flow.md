# 社群月內容規劃 Flow

狀態：已批准試行
主管：阿順
最終決策者：提姆先生

## 觸發條件

客戶需要 IG / FB / Reels 月內容規劃，或每月內容更新節奏。

## 啟動角色

- 客戶成功經理
- 社群主編
- 設計企劃
- 專案助理
- 數據分析師

## 流程

1. 客戶成功經理確認本月客戶目標、主推服務、檔期與限制。
2. 數據分析師整理上月表現與可延續內容。
3. 社群主編建立本月內容主軸、內容支柱、貼文與 Reels 題目。
4. 設計企劃整理每篇視覺需求、素材規格、圖像 Prompt。
5. 專案助理排發布節奏與待補素材。
6. 阿順整合成月內容表，回報提姆先生確認。

## 必要產出

- 本月內容主軸
- 內容支柱
- IG / FB 貼文題目
- Reels 腳本方向
- 視覺需求 Brief
- 待補素材清單
- 發布節奏草稿

## 需要批准

- 每月內容數量
- 檔期活動主軸
- 對外發布內容
- 客戶審稿版本

## 驗收標準

- 每篇內容有目的與 CTA
- 每篇內容有素材需求
- 有明確發布節奏
- 缺少資料已列出
