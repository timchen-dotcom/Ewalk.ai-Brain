# 廣告成效健檢 Flow

狀態：已批准試行
主管：阿順
最終決策者：提姆先生

## 觸發條件

廣告上線後第 1 天、第 3 天、第 7 天，或提姆先生要求檢查廣告成效。

## 啟動角色

- 數據分析師
- 廣告投放專員
- 社群主編
- 設計企劃

## 流程

1. 數據分析師整理花費、觸及、CTR、CPC、CPM、轉換或詢問資料。
2. 廣告投放專員判斷受眾、素材、文案與預算是否需要調整。
3. 社群主編檢查文案與 CTA 是否清楚。
4. 設計企劃檢查素材是否符合活動目標與品牌。
5. 阿順整合成廣告健檢報告，列出建議與需批准事項。

## 必要產出

- 成效數據摘要
- 表現最佳素材 / 文案 / 受眾
- 表現待改善項目
- 可能原因
- 優化建議
- 需提姆先生批准的預算或設定調整

## 需要批准

- 調整實際廣告預算
- 暫停廣告
- 新增廣告組
- 更改轉換目標

## 驗收標準

- 數字、觀察、建議分開
- 不用單一指標做過度結論
- 每個建議都能對應到目標
