# 訂閱費用稽核 Flow

狀態：已批准試行
主管：阿順
最終決策者：提姆先生

## 觸發條件

每月固定盤點訂閱費，或提姆先生要求整理公司工具支出。

## 啟動角色

- 訂閱稽核員
- 數據分析師
- 阿順

## 流程

1. 訂閱稽核員從授權來源整理訂閱通知、發票、收據與續約信。
2. 訂閱稽核員建立工具名稱、金額、週期、用途、來源與狀態。
3. 數據分析師協助統計總額、分類與月增減。
4. 阿順整理保留、觀察、取消 / 降級候選。
5. 提交提姆先生審核。
6. 批准後才進入取消或降級流程。

## 必要產出

- 本月訂閱總額
- 必要保留清單
- 建議觀察清單
- 建議取消 / 降級清單
- 下月續約風險
- 每筆來源

## 需要批准

- 取消訂閱
- 降級方案
- 更改付款方式
- 聯繫客服
- 刪除或匯出資料

## 驗收標準

- 每筆費用有來源
- 保留或取消理由清楚
- 未經批准不做任何金流與取消動作
