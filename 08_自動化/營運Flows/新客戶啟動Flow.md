# 新客戶啟動 Flow

狀態：已批准試行
主管：阿順
最終決策者：提姆先生

## 觸發條件

提姆先生交辦新客戶，或舊客戶新增合作項目。

## 啟動角色

- 客戶成功經理
- 專案助理
- 社群主編
- 設計企劃
- 廣告投放專員
- 數據分析師

## 流程

1. 阿順接收客戶名稱、產業、需求、限制與期限。
2. 客戶成功經理建立需求盤點與待補資料。
3. 專案助理建立第一週任務與節奏。
4. 社群主編建立內容支柱草稿。
5. 設計企劃整理素材與視覺需求。
6. 廣告投放專員判斷是否需要活動與廣告 Brief。
7. 數據分析師建立追蹤欄位與月報框架。
8. 阿順整合成「第一週啟動報告」給提姆先生確認。

## 產出位置

```text
Ewalk.ai Brain/01_客戶/{{客戶名稱}}/
```

## 必要產出

- `00_客戶總覽.md`
- 需求盤點
- 待補資料清單
- 第一週任務
- 內容支柱草稿
- 廣告 / 活動判斷
- 成效追蹤欄位

## 需要批准

- 合作範圍
- 對客戶承諾的交付項目
- 每月更新頻率
- 廣告預算
- 對外正式訊息

## 驗收標準

- 客戶資料夾已建立或更新
- 已分派部門
- 已列出缺少資料
- 已排第一週工作
- 已標註需提姆先生批准事項
