# Google 商家 AI 健檢工具

建立日期：2026-05-25
狀態：架構草案
用途：貼上 Google 商家網址後，產出商家檔案優化建議

## 核心判斷

這個工具可行，但要分成兩種模式：

- `公開健檢模式`：貼上 Google 商家 / Google Maps 網址，分析公開可見內容，產出優化建議。
- `授權管理模式`：客戶授權 Google Business Profile API 後，讀取完整商家資料，協助整理產品、服務、照片、貼文、屬性與成效。

第一版建議先做公開健檢模式，因為不需要登入客戶帳號，也不會誤改正式商家資料。

## 為什麼有人在服務裡打 `#`

推測原因：

- 把服務欄位當成 IG / 社群標籤使用，希望讓關鍵字更明顯。
- 想用 `#關鍵字` 強化 Google 對服務項目的理解。
- 用 `#` 做分類，例如 `#染髮`、`#護髮`、`#頭皮護理`。

實務判斷：

- Google 商家服務欄位不是社群 hashtag 系統，`#` 不會變成可點擊標籤。
- Google 官方服務說明重點是新增實際提供的服務、分類、價格與描述，而不是 hashtag。
- 過度使用 `#` 可能看起來像關鍵字堆砌，對顧客閱讀體驗不好。
- 若服務名稱因此變得不像真實服務，可能被系統視為不自然或低品質內容。

建議做法：

- 服務名稱用顧客會搜尋、也看得懂的自然語句。
- 服務描述補充適合對象、流程特色、效果邊界與注意事項。
- 不需要在服務名稱前面加 `#`。
- 如果要分類，使用 Google 商家服務分類或內部表格分類，不用 hashtag。

## 官方規則重點

依 Google Business Profile 官方文件：

- 商家可以新增服務，並可依商家類別選擇建議服務或新增自訂服務。
- 服務可以加入描述與價格。
- 部分自訂服務可能被系統自動拒絕，例如粗俗文字、亂碼、個資、價格或電話號碼。
- Google Business Profile API 可以管理 predefined services 與 custom services，但更新服務清單時需注意 API 行為。
- Google local ranking 的公開建議是提供完整、詳細且正確的商家資料。

## 工具輸入

### MVP 輸入

- Google 商家網址
- 客戶名稱
- 產業類型
- 主要服務地區
- 目前想推的服務
- 官網 / 預約頁 / LINE OA
- 商家截圖或人工貼上的可見資料

### 進階輸入

- Google Business Profile API 授權資料
- Google Search Console
- GA4
- 官網服務頁 sitemap
- Google 評論匯出
- 競品 Google 商家網址

## 工具輸出

### 1. 商家基本資料健檢

- 商家名稱是否自然、是否符合現實品牌
- 主要分類與次要分類是否合理
- 地址、服務地區、電話、網站、營業時間是否完整
- 商家描述是否清楚
- 是否有連到正確官網或預約頁

### 2. 產品與服務優化

- 建議新增哪些服務項目
- 哪些服務應該拆細
- 哪些服務名稱太像關鍵字堆砌
- 是否建議把服務也做成產品卡
- 每個產品 / 服務需要什麼圖片
- 每個服務應搭配哪個官網服務頁

### 3. AI 圖像需求

- 依服務項目產出圖片需求
- 判斷哪些服務適合使用真實照片
- 判斷哪些服務可用 AI 情境圖
- 避免生成不實效果圖、誇大前後對比或錯誤醫療暗示
- 產出可交給設計企劃的圖像 prompt

### 4. 內容與貼文建議

- 建議 Google 商家貼文主題
- 建議 FAQ / Q&A
- 建議評論引導方向
- 建議服務頁與 Google 商家的互相連結

### 5. 風險檢查

- 是否使用過度 SEO 關鍵字
- 是否出現療效、保證、誇大字眼
- 是否出現電話、價格或個資放錯欄位
- 是否可能違反產業限制，例如醫美、保健食品、金融、法律

## MVP 流程

1. 使用者貼上 Google 商家網址。
2. 使用者補上產業、地區、主要服務。
3. 阿順讀取公開頁面或使用者提供的截圖 / 文字。
4. 工具產出 Google 商家健檢報告。
5. 工具產出產品、服務、圖片與貼文待辦。
6. 人工確認後，再進 Google 商家後台修改。

## 進階自動化流程

```text
Google 商家網址
↓
抓取公開可見資訊 / API 授權資料
↓
比對官網服務頁與商家分類
↓
AI 產出產品、服務、圖片、貼文、FAQ 建議
↓
阿順產出待辦與風險分級
↓
人工確認
↓
更新 Google 商家
↓
每月追蹤觀看、搜尋、來電、路線、網站點擊
```

## 權限與風險

- 第一版只分析，不自動修改 Google 商家。
- 正式更新商家資料前，需要客戶或提姆確認。
- 服務與產品圖若用 AI 生成，需標註不可誤導顧客。
- 醫美、保健品、法律、金融等高風險產業需人工審稿。
- 若要串 Google Business Profile API，需要客戶授權。
