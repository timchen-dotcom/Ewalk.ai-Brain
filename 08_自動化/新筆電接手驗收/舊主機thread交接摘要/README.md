# 舊主機 thread 交接摘要

## 用途

這個資料夾用來收 Mac Studio 舊 Codex 釘選 thread 的交接摘要。

每個 thread 都用固定格式回填，讓新筆電可以接續工作，不依賴舊主機視窗長期保留。

## 目前狀態

2026-06-05 已先以新筆電可讀的 Vault 脈絡完成 P0 / P1 / P2 摘要預回填。

這些檔案已可支撐新筆電日常接續工作；Mac Studio 原 thread 仍建議逐項輸出補強，補回聊天中未沉澱到 Vault 的決策、提醒節奏、工具設定與批准事項。

## 使用方式

1. 在 Mac Studio 開啟舊 Codex thread。
2. 將 `00_交接摘要模板.md` 的 prompt 貼到該 thread。
3. 把舊 thread 輸出的交接摘要貼回對應檔案的「原 thread 補強」區段。
4. 若沒有對應檔案，複製模板建立新檔。
5. 涉及 token、secret、密碼、API key 時，只記路徑與處理方式，不貼內容。

## 優先順序

- P0：工作交辦窗口、阿順主窗口、霖老師線上車庫。
- P1：韓食日常鍋物、TheVision、TheDay、正官庄、阿順語音系統。
- P2：簡報、Higgsfield、Google 評論、社群追蹤、STAR / Inebrya / 其他素材工作。

## 完成標準

每份摘要至少要有：

- 目前狀態
- 已完成事項
- 待補資料
- 風險與需提姆先生批准事項
- 下一步可執行清單
- 相關檔案與連結
- 建議歸檔位置
