## 另行處理

- 圖片與視覺素材：需後續依客戶、專案、素材用途盤點。
- PDF、zip、docx、pptx、key、xlsx：需判斷是否為正式交付品、原始資料或暫存輸出。
- `.obsidian` 與本機設定：暫不提交，避免把個人工作環境誤當成 Vault 共用規則。
- token、secret input URL、local config：暫不提交，需改以安全憑證流程管理。
