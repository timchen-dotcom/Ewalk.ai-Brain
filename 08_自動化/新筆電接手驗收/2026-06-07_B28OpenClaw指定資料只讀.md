# 2026-06-07 B28 OpenClaw 指定資料 Read-only

## 一句話結論

B28 讓 OpenClaw 可以讀取正式 Brain 的指定資料夾，開始自己消化工作資料；但只限 read-only，不讀接案碟、不讀 secrets、不寫正式文件、不產生外部副作用。

## 允許讀取範圍

```text
01_客戶
02_內容
03_廣告
13_SOP流程
14_每日工作
```

## 允許寫入範圍

沿用 B27：

```text
00_收件匣/OpenClaw草稿
14_每日工作/OpenClaw草稿回填
08_自動化/openclaw/action-queue
```

## 仍然禁止

- 不讀 `/Volumes/提姆接案碟`。
- 不讀 `.git`、`.obsidian`、secret、token、API key。
- 不寫正式客戶文件。
- 不發文、不部署、不寫 production Firebase。
- 不接正式客戶通道。
- 不操作廣告預算、金流、帳務或付款設定。

## 執行方式

在 Mac Studio：

```zsh
cd "$HOME/Desktop/Ewalk.ai 自動化系統/Ewalk.ai Brain"
git pull
cd "$HOME/Desktop/Ewalk.ai 自動化系統/Ewalk.ai Brain/08_自動化/openclaw"
zsh "./B28OpenClaw指定資料只讀.command"
```

## B28 通過後代表什麼

代表 OpenClaw 可以進入受控上工模式：

- 可以讀指定資料夾。
- 可以把成果寫到指定草稿區。
- 可以用 action queue 草稿交給 Codex / Command Center。

不代表：

- 可以讀完整 Brain。
- 可以讀接案碟。
- 可以正式發文或部署。
- 可以寫 production Firebase。
- 可以接正式客戶通道。
- 可以碰廣告預算或金流。
