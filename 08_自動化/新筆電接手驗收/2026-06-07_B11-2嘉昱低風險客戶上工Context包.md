# 2026-06-07 B11-2 嘉昱低風險客戶上工 Context 包

## 一句話結論

這是 OpenClaw B11 第一個真實低風險上工任務：由 Codex 主窗口整理嘉昱隔熱膜 context，OpenClaw 只依貼入文字產出低風險客戶上工單。

## 任務邊界

OpenClaw 只允許：

- 讀取本段人工貼入 context。
- 整理摘要、任務分類、待辦、風險與需批准事項。
- 產出純文字客戶上工單草稿。

OpenClaw 不允許：

- 讀正式 Brain。
- 讀客戶資料夾或接案碟。
- 使用工具、exec、搜尋。
- 寫檔、寫 Obsidian、commit / push。
- 接正式客戶通道。
- 發文、部署、寫 Firebase。
- 操作廣告預算、金流、帳務或付款設定。
