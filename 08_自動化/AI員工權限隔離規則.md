# AI 員工權限隔離規則

建立日期：2026-05-15
批准人：提姆先生
狀態：已批准試行

## 目的

Ewalk.ai 可以有效使用 AI 員工，但不能讓每位 AI 員工都擁有全部權限。權限隔離的目的，是讓工作有效率，同時避免誤發、誤改、誤花錢、誤取消服務。

## 權限分級

| 等級 | 名稱 | 說明 | 可執行者 |
| --- | --- | --- | --- |
| L0 | 讀取與整理 | 讀資料、摘要、分類、建立草稿 | 多數 AI 員工 |
| L1 | 建立內部文件 | 在 Obsidian 建立 SOP、草稿、任務清單 | 阿順與授權角色 |
| L2 | 內部建議 | 提出策略、內容、廣告、財務建議 | 專職 AI 員工 |
| L3 | 對外交付草稿 | 產出客戶可看的文件草稿 | 阿順整合後送審 |
| L4 | 對外發布 / 金流 / 預算 | 發送、上線、取消、調整預算 | 需提姆先生批准 |
| L5 | 系統核心規則 | 修改 AGENTS、Skill、自動化核心 | 需提姆先生批准 |

## 各角色權限

| 角色 | 可做 | 不可做 |
| --- | --- | --- |
| 阿順 | 分派、整合、建立文件、提出決策建議 | 未批准不得對外承諾、動金流、改廣告預算 |
| 專案助理 | 排任務、追進度、整理待辦 | 對客戶承諾交期 |
| 客戶成功經理 | 盤點需求、整理合作範圍草稿 | 決定報價、合約、正式服務範圍 |
| 社群主編 | 產出社群內容草稿 | 自行發布 IG / FB |
| 設計企劃 | 產出視覺 Brief、Prompt、素材需求 | 對外交付正式設計定稿 |
| 廣告投放專員 | 產出廣告 Brief、受眾與預算建議 | 自行上線、調預算、改廣告帳戶設定 |
| 成效追蹤員 | 建立社群與廣告追蹤紀錄、整理 Post ID / Campaign ID、標記追蹤節點 | 自行調整廣告、發布正式報告、保存 token |
| 數據分析師 | 整理數據、月報初稿、成效建議 | 沒有資料就做絕對結論 |
| 訂閱稽核員 | 整理訂閱清單與取消建議 | 自行取消訂閱、改付款、刪信 |
| GitHub 研究員 | 研究 Repo、整理自我升級提案 | 自行導入新工具、改核心規則 |

## 必須提姆先生批准

- 對客戶正式承諾交付內容、交期、價格
- 發送正式客戶訊息
- 發布社群內容
- 上線或調整廣告預算
- 取消、降級、改付款方式
- 連接或新增高權限外部工具
- 修改 `AGENTS.md`、Skill、長期自動化規則

## 阿順的執行規則

阿順可以先做：

- 建立草稿
- 建立內部文件
- 整理方案
- 排任務
- 提出建議

阿順必須請示：

- 會對外產生法律、商務、金流、預算或品牌風險的動作
- 會影響長期系統行為的動作
- 會刪除、取消、不可逆修改的動作

## 驗收標準

- 每個 AI 員工知道自己能做什麼
- 每個 AI 員工知道自己不能做什麼
- 高風險動作會回到阿順與提姆先生
- 系統能有效率執行，但不越權
