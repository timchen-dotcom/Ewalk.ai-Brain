## 最快採購路線

### 主機

買：

```text
Mac mini M4
24GB 統一記憶體
512GB SSD
Gigabit Ethernet
```

理由：

- 24GB 是重點，512GB 可以靠外接 SSD 補。
- 不等 1TB / 10Gb Ethernet 特規。
- 目前 Ewalk.ai 第一階段瓶頸不是網路，而是任務紀錄、批准閘、資料隔離與自動化流程。

不要買：

```text
16GB / 256GB
```

理由：很快會卡在 Docker、瀏覽器自動化、logs、cache、node_modules 與多工具並行。

## SSD 搭配

### 最推薦

```text
OWC Express 1M2 USB4 / 40Gbps 外接盒
  + 4TB NVMe SSD
```

理由：

- Mac mini M4 後方 Thunderbolt 4 可到 40Gb/s。
- USB4 / Thunderbolt 等級比較適合當長期工作碟。
- 比 USB 10Gb/s Hub 類產品更適合放 Docker、logs 與 agent outputs。

### 可以但不優先

```text
Satechi Mac mini M4 Stand & Hub with SSD Enclosure
```

理由：

- 外型整潔、很像 Mac mini 底座。
- 但 SSD enclosure 是 10Gb/s 等級，比 40Gb/s 外接盒慢。
- 可當第二顆資料碟或整理型 hub，不建議當核心工作碟。

### 不建議當核心工作碟

```text
Samsung T9 / Crucial X10 Pro 這類 USB 3.2 Gen 2x2 SSD
```

理由：

- 它們標榜 2000MB/s，但 Mac mini 上常無法完整吃到 20Gb/s。
- 最後可能變成 10Gb/s 等級。
- 能用，但不是最佳長期主工作碟。

## 二手 Mac Studio M1 Max 判斷

提姆先生看到的二手選項：

```text
Mac Studio M1 Max
10 核心 CPU
24 核心 GPU
32GB RAM
512GB SSD
2022/8 購買，已過保
賣價 NT$40,000
```

採購結論：

```text
不建議用 NT$40,000 買。
```

理由：

- 這台效能仍然很好，但本質上不是升級，比較像再買一台與提姆先生現有 Mac Studio 接近的第二主機。
- 已過保，若主機板、SSD、電源或 Thunderbolt 埠出問題，維修成本與停機風險都會落在 Ewalk.ai。
- `M4 Pro / 24GB / 512GB` 新機約 NT$46,900，價差約 NT$6,900，但有新機保固、更新世代 CPU、Thunderbolt 5 與更長系統支援期。
- `M4 / 24GB / 512GB` 新機約 NT$33,900，若能買到，價格甚至低於這台二手。

可接受條件：

| 價格 | 判斷 |
| --- | --- |
| NT$40,000 | 不建議 |
| NT$35,000 以下 | 可考慮，但仍不優先 |
| NT$30,000 到 NT$32,000 | 可以作為「立刻拿到的隔離主機」 |
| NT$30,000 以下 | 若驗機正常，可以買 |

二手驗機必檢：

- 現場開機到 macOS，確認「關於這台 Mac」規格是 `M1 Max / 32GB / 512GB`。
- 賣家現場登出 Apple ID，關閉「尋找我的 Mac」。
- 執行「清除所有內容和設定」，重開後要進入全新設定畫面。
- 連上網路後，不可出現「遠端管理 / Remote Management」或公司控管畫面。
- 檢查所有 Thunderbolt / USB-C、HDMI、網路孔、SD 卡、耳機孔。
- 聽風扇是否異常，機身是否摔傷、進水、拆修。
- 問清楚是否有原盒、發票或購買證明。

公司主機判斷：

- 若目標是「最快今天拿到一台乾淨隔離主機」，二手 Mac Studio 可以考慮，但要大幅議價。
- 若目標是「嶼晴出生前穩定長跑、少維修風險」，優先買新 M4 / M4 Pro。

## 找不到 24GB 現貨時的決策

2026-06-02 狀況：台中門市與主要網路電商若都找不到 24GB 現貨，不能讓採購卡住系統上線。

### 最穩策略

```text
現在立刻用提姆先生現有 Mac Studio 建立「臨時隔離工作區」
同時排隊 / 訂購 24GB 以上新主機
```

做法：

- 現有 Mac Studio 不重置。
- 建立獨立使用者 `ewalk-runner`。
- 外接 SSD 格式化成 APFS 加密，專門放阿順系統。
- 先完成 Firebase、Command Center、ai_runs、客戶資料流程、自動化排程。
- 新主機到貨後，把外接 SSD 與系統搬過去。

理由：

- 不犧牲安全性太多，也不拖延開工。
- 8 月前要完成的是「流程與治理」，不是等硬體完美才開始。

### 若今天一定要買一台

可買：

```text
Mac mini M4 / 16GB / 512GB
```

但定位必須改成：

```text
阿順入口節點 / 輕量執行節點
```

適合做：

- Firebase / Vercel / GitHub / Obsidian 自動化。
- 每日摘要。
- Gmail 訂閱稽核。
- 美感趨勢週報。
- 客戶資料整理。
- 單一瀏覽器自動化。
- 雲端 LLM API 任務。

不適合做：

- 多個瀏覽器同時自動化。
- 本地大型模型。
- 大量影像生成 / 影片處理。
- Docker 與多工具長時間並行。
- 當完全體主力機長跑。

### 若買 16GB，系統配置要調整

- 不跑本地 LLM。
- 不同時開多個瀏覽器自動化。
- Docker 服務數量壓低。
- Logs / cache / outputs 全部放外接 SSD。
- 重任務交給雲端 API、Vercel、Firebase 或現有 Mac Studio。
- 之後 24GB / 32GB / 48GB 主機到位，再把 16GB 轉成入口節點。

### 16GB 與 24GB 的工作差異

16GB 不是不能做重任務，而是「同時做多件重任務」時更容易進入記憶體壓力。

阿順系統常見記憶體消耗：

| 工作項目 | 可能消耗 |
| --- | --- |
| macOS 系統與背景服務 | 4GB 到 6GB |
| Chrome / Playwright 瀏覽器自動化 | 1GB 到 4GB+ |
| VS Code / Codex / Claude Code / Gemini CLI | 1GB 到 4GB+ |
| Docker / Firebase emulator / 本地服務 | 2GB 到 8GB+ |
| 多個客戶資料、文件、素材、分頁 | 1GB 到 6GB+ |
| 本地 LLM 或影像 / 影片處理 | 8GB 到 20GB+ |

16GB 適合：

- 單一主線任務。
- 雲端 LLM API。
- Obsidian / Firebase / Vercel / GitHub / Gmail 類自動化。
- 每日摘要、週報、訂閱稽核、客戶資料整理。
- 一次一個瀏覽器自動化流程。

24GB 適合：

- 同時開發、跑自動化、開瀏覽器、整理資料。
- 多個工具並行。
- Docker 與瀏覽器自動化一起跑。
- 長時間背景任務比較穩。
- 比較接近阿順完全體主力機。

白話判斷：

```text
16GB = 可以上班，但要排隊做事。
24GB = 可以同時開幾個部門一起做事。
32GB 以上 = 比較像公司主力營運主機。
```

如果 16GB 記憶體不夠，macOS 會把部分資料暫時挪到 SSD 當交換空間，短期可以救急，但長時間大量交換會變慢，也會讓系統反應不穩。

### 目前決策建議

| 情境 | 決策 |
| --- | --- |
| 找得到 M4 Pro / 24GB / 512GB 現貨 | 直接買 |
| 找不到 24GB，但能訂到 1-3 週內到貨 | 訂 24GB，同時用現有 Mac Studio 開工 |
| 24GB 要等很久，但 16GB/512GB 今天可買 | 可買 16GB 當入口節點，但不要當完全體主力 |
| 想省錢買二手 M1 Max | 價格要壓到 NT$30,000-32,000 才合理 |

## 反向配置方案：Mac Studio 給阿順，16GB Mac mini 給提姆先生

2026-06-02 新判斷：如果提姆先生大部分重工作會逐步交給阿順，自己主要使用 Canva、文書、瀏覽器、雙螢幕與日常管理，那反向配置更合理。

### 硬體分工

| 主機 | 角色 | 理由 |
| --- | --- | --- |
| 現有 Mac Studio M1 Max / 32GB | 阿順主力營運主機 | 記憶體較大，適合 Codex、瀏覽器自動化、Docker、Firebase、資料整理與多工具並行 |
| 新 Mac mini M4 / 16GB / 512GB | 提姆先生日常工作機 | Canva、文書、簡報、雙螢幕、客戶溝通與審核足夠，且新機乾淨、省電、桌面簡潔 |

### 優點

- 不再卡 24GB 現貨。
- 阿順直接用 32GB 主機，工作能力比 16GB Mac mini 更穩。
- 提姆先生日常使用 16GB M4 已足夠，尤其重任務逐步交給阿順後。
- 新 Mac mini M4 支援多螢幕，符合提姆先生喜歡多畫面的工作習慣。
- 花費較低，能最快啟動「爸爸模式」。

### 風險

- 現有 Mac Studio 目前混有私人資料、工作資料與瀏覽器登入狀態，不能直接讓阿順長期跑。
- 需要先做「軟隔離」：
  - 建立 `ewalk-runner` 專用使用者。
  - 阿順只在 `ewalk-runner` 裡跑。
  - Ewalk.ai 系統資料放外接 APFS 加密 SSD。
  - 不登入提姆先生私人 Apple ID。
  - 不掛載私人資料碟。
  - 重要 API Key 與客戶資料權限分層。

### 建議做法

