# 每週整理 SOP

每週固定整理 `00_收件匣/語音轉錄`，避免語音筆記堆積。

## 步驟

1. 打開 `00_收件匣/語音轉錄`
2. 逐篇檢查狀態
3. 將 `待整理` 的筆記用 `整理提示詞.md` 整理
4. 判斷歸檔位置
5. 移動到對應資料夾
6. 在原始筆記或總覽頁補上連結
7. 同步 Obsidian Sync

## 歸檔判斷

| 內容類型 | 目的地 |
| --- | --- |
| 客戶討論 | `01_客戶/客戶名稱/` |
| 社群內容靈感 | `02_內容/IG內容` |
| Reels 靈感 | `02_內容/短影音Reels` |
| 廣告想法 | `03_廣告` |
| 月報洞察 | `04_報表/月報` |
| 會議紀錄 | `07_會議` |
| 方法論 | `09_知識庫` |

## 完成定義

- [ ] 每篇語音筆記都有摘要
- [ ] 待辦已獨立列出
- [ ] 已歸檔到正確資料夾
- [ ] 相關客戶總覽已補連結
- [ ] 已完成同步
