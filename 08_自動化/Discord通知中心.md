# Discord 通知中心

這裡記錄 Ewalk.ai 工作系統的 Discord 通知分流。

## 頻道分工

| Discord 頻道 | 設定代號 | 用途 | 目前狀態 |
| --- | --- | --- | --- |
| `#每日接續` | `daily_handoff` | 每天早上 10:00 從 Obsidian 昨日 `明天接續` 整理到今日待辦 | 已接通 |
| `#重要提醒` | `important` | 會議、截止日、必須即時看到的提醒 | 已接通 |
| `#客戶待辦` | `customer_tasks` | 客戶回覆、交付、追蹤事項、Google 評論每日追蹤摘要 | 已接通 |
| `#系統通知` | `system` | 自動化成功、失敗、異常提醒 | 已接通 |
| `#想法收件匣` | `inbox` | 臨時想法、靈感、待整理事項 | 已接通 |
| `#自我升級` | `self_upgrade` | GitHub / 開源自我升級情報、可升級項目、需提姆核准的系統改善建議 | 已接通 |
| `#美感趨勢搜集` | `aesthetic_trends` | 每日美髮、美妝、時尚、潮流趨勢收集與每週五週報摘要 | 已接通 |

## Webhook 設定位置

Webhook URL 放在：

`08_自動化/本地AI-Gemma/config.local.json`

這個檔案已排除 Git，不會同步到版本控管。

## 建議通知規則

- 每日例行事項放 `#每日接續`
- 會影響今天工作安排的放 `#重要提醒`
- 客戶相關且需要追蹤的放 `#客戶待辦`
- Google 評論新增、未回覆與 SLA 追蹤摘要放 `#客戶待辦`；今天到期或逾期時同步放 `#重要提醒`
- 設計需求先進 `#專業經理人🤖阿順`，由阿順整理成 ChatGPT Images 2.0 指令
- 自動化流程錯誤或成功回報放 `#系統通知`
- 還沒分類的想法先放 `#想法收件匣`
- 每日自我升級情報優先放 `#自我升級`，尚未接通前可先放 `#系統通知`
- 每日美感趨勢收集與每週週報優先放 `#美感趨勢搜集`，尚未接通前可先放 `#系統通知`
