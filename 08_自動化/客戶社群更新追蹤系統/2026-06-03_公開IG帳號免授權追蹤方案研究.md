# 2026-06-03 公開 IG 帳號免授權追蹤方案研究

研究日期：2026-06-03
主管：阿順
需求來源：提姆先生詢問是否能不用取得客戶授權，追蹤 `thevision_olivia` 這類公開 IG 帳號每週是否有發文
狀態：已研究，建議做小規模公開資料 Scraper API 試點

## 結論

可以做，但要分清楚兩條路：

| 路線 | 是否需要客戶授權 | 能否追蹤公開帳號 | 適合用途 | 風險 |
| --- | --- | --- | --- | --- |
| Meta 官方 Instagram API | 需要 | 不適合追蹤未授權帳號 | 自家或已授權客戶的 IG 商業 / 創作者帳號 | 權限申請、帳號綁定、App Review |
| 公開資料 Scraper API | 不一定需要 | 可以，前提是帳號公開 | 每週檢查有沒有發文、貼文日期、貼文連結 | 平台條款、穩定性、供應商依賴 |

對 Ewalk.ai 的需求來說，如果只是要追蹤：

- 這週有沒有發文
- 發了幾篇
- 最新貼文日期
- 貼文連結
- 是否低於每週目標

可以採用公開資料 Scraper API，不需要每個客戶都先授權 Meta。

但如果要抓：

- 觸及
- 儲存
- 分享
- 粉絲洞察
- 精準互動數據
- 私人帳號內容

仍然需要官方 Meta / Instagram 授權，或根本不應該抓。

## 官方 API 現況

Instagram Basic Display API 已於 2024-12-04 停用。Zapier 與 Hootsuite 的說明都指出，個人帳號整合受到影響，後續主要轉向 Instagram for Business / Business 或 Creator 帳號。

實務意思：

- 官方 API 不再適合拿來讀取任意公開個人 IG。
- 官方 API 比較適合「客戶正式授權後」做穩定營運數據。
- 如果 `thevision_olivia` 是未授權的公開帳號，官方 Meta API 不是正確路線。

參考：

- Zapier：`https://help.zapier.com/hc/en-us/articles/32429170578317-Instagram-app-deprecation-on-Dec-4-2024`
- Hootsuite：`https://hootsuite1614365228.zendesk.com/hc/en-us/articles/30378833282203-Instagram-Personal-profile-deprecation-December-2024`

## 可用外部工具類型

### 1. Apify Instagram Scraper

適合 Ewalk.ai 先做 MVP。

優點：

- 可用 profile URL 或 handle 抓公開帳號近期貼文。
- 可輸出 JSON / CSV / Excel。
- 可用 REST API 或 SDK 串到 Node.js。
- 價格按結果量計算，低量監控成本較容易控制。

限制：

- 屬於公開資料抓取，不是官方 Meta API。
- 供應商 Actor 可能因 Instagram 前端變更而需要維護。
- 不應抓私人帳號或敏感資料。

參考：

- Apify Instagram Scraper 教學：`https://use-apify.com/docs/how-to-use-apify/scrape-instagram`
- Apify Instagram Scraper Actor：`https://apify.com/parseforge/instagram-scraper`

### 2. Bright Data Social Media Scraper API

適合未來大量客戶、較正式的資料供應鏈。

優點：

- 有社群平台 Scraper API，包含 Instagram profiles、posts、reels、comments。
- 較偏企業級，穩定性與資料處理能力通常比單一小工具強。
- 可擴展到多平台。

限制：

- 成本與帳務門檻可能比 Apify 高。
- 需要評估合規、資料保留與客戶告知方式。

參考：

- Bright Data Social Media Scraper APIs：`https://docs.brightdata.com/api-reference/scrapers/social-media-apis/overview`

### 3. PhantomBuster / RapidAPI 類工具

適合短期測試，不建議做 Ewalk.ai 核心長期系統第一選擇。

優點：

- 上手快。
- 有些工具可以用 no-code 或簡單 HTTP Request。

限制：

- 很多工具需要 Cookie 或登入帳號，帳號風險較高。
- Instagram UI 變更時容易壞。
- 不同供應商資料格式差異大。

參考：

- PhantomBuster 比較資訊：`https://hikerapi.com/help/best-instagram-scraping-api`
- PullAPI 社群 Scraper API：`https://pullapi.com/`

## 建議 Ewalk.ai 採用方案

### 第一階段：公開貼文頻率追蹤 MVP

工具建議：Apify Instagram Scraper。

追蹤範圍：

- 公開 IG 帳號
- 近 7 天貼文
- 近 30 天貼文
- 貼文 ID
- 發文時間
- permalink
- caption 摘要
- media type

不追蹤：

- 私人帳號
- Stories
- 粉絲名單
- 留言明細
- 私訊
- 個資欄位
- 敏感互動資料

### 第二階段：整合既有追蹤系統

在 `run-social-frequency-tracker.mjs` 增加資料來源：

```json
{
  "platform": "instagram",
  "displayName": "TheVision Olivia IG",
  "enabled": true,
  "source": "apify_instagram_public",
  "handle": "thevision_olivia",
  "targetPerWeek": 3,
  "targetPerMonth": 12,
  "tokenEnv": "APIFY_TOKEN"
}
```

輸出仍沿用現有欄位：

- 本週目標
- 本週已發
- 本週缺口
- 本月至今應發
- 本月已發
- 月底仍需
- 狀態

### 第三階段：每週自動巡檢

每週固定跑：

1. 讀取客戶公開帳號清單。
2. 對每個 handle 抓近期公開貼文。
3. 只保留發文時間、連結、平台、帳號、貼文 ID。
4. 計算缺口。
5. 產出週報。
6. 缺口項目進 Discord 通知草稿。

## 風險控管

必須遵守：

- 只追公開帳號。
- 不繞過私人帳號。
- 不大量抓留言、粉絲、個資。
- 只保存營運需要的最小資料：發文時間、連結、平台、帳號、貼文 ID。
- 若客戶合約要求正式數據，仍應改用 Meta 授權。
- 對外使用報告時，說法用「公開頁面巡檢」或「公開貼文更新追蹤」，不要說成官方 API 數據。

提姆先生已提供正式連結：

- `https://www.instagram.com/thevision_olivia?igsh=bmJpOHdkZWg5NXNw`

追蹤設定使用乾淨 URL：

外部搜尋結果可對上帳號標題：

- `王涵Olivia｜THEVISION髮廊創始人 淡水髮廊 - @thevision_olivia`

下一步仍要確認：

- 帳號是否拼字正確
- 帳號是否公開
- 是否為個人設計師帳號
- 是否允許 Ewalk.ai 只做公開發文頻率巡檢

如果帳號公開，Apify / Bright Data 類工具理論上可每週抓一次近期貼文，用來判斷是否有更新。

## 建議下一步

1. 建立 `clients.public-ig.example.json`，把 `thevision_olivia` 加入公開追蹤試點。
2. 申請或使用 Apify API token，先跑 1 到 3 個公開帳號。
3. 將抓回來的資料正規化成現有 `posts` schema。
4. 每週自動跑一次，輸出公開 IG 更新追蹤報告。
5. 若客戶願意正式授權，再升級成 Meta 官方 API。

## Apify 實作規格草案

### 環境變數

```env
APIFY_TOKEN=apify_api_token_goes_here
```

### 輸入

```json
{
  "directUrls": ["https://www.instagram.com/thevision_olivia/"],
  "resultsType": "posts",
  "resultsLimit": 30,
  "searchType": "user"
}
```

### 正規化成追蹤系統格式

Apify 回傳資料進入追蹤系統前，只保留：

```json
{
  "clientId": "thevision-designers",
  "platform": "instagram",
  "accountId": "thevision_olivia",
  "postId": "shortCode 或 id",
  "publishedAt": "timestamp",
  "permalink": "url",
  "caption": "caption 前 120 字",
  "mediaType": "typeName"
}
```

### 成功標準

- 可讀取 `thevision_olivia` 最近 30 筆公開貼文。
- 可計算最近 7 天與本月貼文數。
- 報告不保存留言、粉絲名單、私訊或個資。
- 若帳號無法抓取，狀態標記為 `待確認`，不硬抓。
