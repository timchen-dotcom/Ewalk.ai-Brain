# Google 真實評論整理小幫手

## 用途

這是一個給美業門市現場使用的 Google 評論輔助工具。目標不是製造假評論，而是幫助真實消費者把今天的服務體驗整理成一段自然、具體、可自行修改的評論草稿。

適合用在髮廊、美甲、美睫、SPA、醫美、健身教練、餐飲與其他重視 Google 商家評論的服務型門市。

## 使用時機

- 顧客結帳後，櫃檯邀請顧客留下真實評論。
- 顧客不知道怎麼寫，只能寫「很棒」「服務很好」時。
- 店家希望評論自然帶到地區、品牌、服務項目與服務人員，但不硬塞關鍵字。
- 多分店或多設計師希望累積更完整的服務語意資料。

## 檔案

- `index.html`：可直接開啟的靜態 MVP 工具。
- `README.md`：本說明文件。

## 第二版功能

目前第二版是多客戶 AI 輔助版，先用結構化選項收集顧客真實體驗，再由後端 OpenAI 低成本文字模型產生較自然、不模板化的評論草稿。若 API 暫時失敗，前端會自動退回本地規則版，不影響現場使用。

1. 管理者可在同一個工具內建立多個客戶設定檔。
2. 每個客戶各自設定品牌、所在地區、服務項目、服務人員與 Google 評論連結。
3. 工具可產生該客戶專屬現場使用連結與 QR Code。
4. 顧客選擇實際服務項目與服務人員。
5. 顧客勾選實際感受，或補一句自己的經驗。
6. 工具優先用 AI 產生 3 則不同語氣、不同句型的評論草稿。
7. 顧客自行挑選、修改與複製。
8. 工具提供 Google 評論連結與 QR 圖下載，QR 圖可放入 Canva 立牌設計。

## AI 產生原則

- 後端 API：`/api/review-drafts`。
- 模型：低成本文字模型，用於簡單文字整理。
- 前端不保存 OpenAI API Key，金鑰只放在 Vercel 環境變數。
- AI 提示詞要求只根據顧客輸入整理，不捏造服務細節。
- 目標是降低罐頭感、提高真實個人化，不是規避平台審查。
- 若 AI API 失敗，工具會退回規則版句型，避免現場流程中斷。

## 管理者流程

1. 打開管理入口：`https://ewalk-tools-google-review-helper.vercel.app?admin=1`。
2. 輸入管理 PIN。
3. 進入「客戶設定」。
4. 選擇既有客戶，或點「新增客戶」。
5. 填入客戶設定檔名稱、品牌名稱、地區、Google 評論連結、服務項目與服務人員。
6. 點「儲存設定」。
7. 點「產生現場使用連結」。
8. 進入「生成 QR 碼」，下載評論小幫手 QR 與 Google 商家評論 QR。
9. 將 QR 圖放入 Canva 或其他設計工具製作立牌。

## 顧客流程

1. 顧客掃第一個 QR Code，進入該客戶專屬評論小幫手。
2. 顧客選擇實際服務項目與服務人員。
3. 顧客勾選實際感受，或補一句自己的經驗。
4. 工具產生 3 則不同語氣的評論草稿。
5. 顧客自行挑選、修改與複製。
6. 顧客點擊或掃第二個 QR Code 前往 Google 商家評論頁。
7. 顧客自行確認內容符合實際體驗後送出。

## 合規原則

- 不保證五星。
- 不誘導只留下正面評論。
- 不憑空捏造未提供的服務細節。
- 不把「避開 Google 偵測」作為產品目的。
- 每則文字必須依照顧客輸入的真實服務與感受整理。
