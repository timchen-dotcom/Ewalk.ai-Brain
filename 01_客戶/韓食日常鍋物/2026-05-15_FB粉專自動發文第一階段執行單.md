10. 發布後回寫 post id 與發布紀錄。

## Token 安全交接規則

- 提姆先生不用把 token 貼給阿順。
- 阿順可以操作後台與建立測試工具，但不讀取、不保存、不回寫任何 token 明文。
- token 只能進入後端環境變數或安全密鑰管理。
- 若畫面出現 token，阿順只判斷流程是否完成，不抄錄內容。
- 正式測試發文前，阿順要先回報貼文內容、粉專、發文方式與可能影響，等提姆先生批准後才執行。
