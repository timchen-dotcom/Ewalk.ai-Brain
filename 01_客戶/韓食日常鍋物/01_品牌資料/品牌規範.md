## 1. 品牌宣言 (Brand Manifesto)

> **「讓韓食，回到餐桌的日常。」**
>
> 我們相信，韓式料理不該只存在於週末聚會與高客單的燒肉店裡。
> 它應該像一碗熱騰騰的大醬湯、一鍋滾燙的部隊鍋——
> 出現在每一個疲憊的平日夜晚，成為年輕世代的剛需。
>
> **韓食日常鍋物**，以「韓食的靈魂，台式火鍋的骨架」為核心哲學：
> 我們保留韓式料理最令人成癮的風味記憶（泡菜的發酵、辣醬的醇厚、黃銅器皿的儀式感），
> 卻用台灣平價小火鍋的高效營運骨架，打破價格門檻。
>
> 我們不是另一間韓式餐廳。
> 我們是**重新定義日常外食的連鎖鍋物品牌**。

### 1.1 品牌人格 (Brand Persona)

| 維度 | 定義 |
|---|---|
| **年齡感** | 22–35 歲，都會年輕上班族、大學生、小家庭 |
| **個性** | 熱情、直接、有主見、懂生活、不鋪張 |
| **語氣** | 像一位剛從首爾回來的朋友，推薦你一家他常去的店 |
| **禁忌** | 絕不賣弄文化、不炫技、不使用老派韓流元素（如韓服、傳統紋樣） |

### 1.2 品牌承諾 (Brand Promise)

一、**價格日常**：主食 $110 起，吃得起的韓式鍋物。
二、**風味正統**：核心醬料、泡菜風味不妥協。
三、**空間高級**：拒絕昏暗油膩，給年輕人一個能拍照、能久坐的明亮空間。
四、**效率專業**：自助點餐、模組化出餐，從進店到上桌 8 分鐘內。

## 2. 戰略定位與降維打擊邏輯

### 2.1 市場缺口

台灣餐飲市場存在一個被忽視的中間地帶：
- 傳統韓式燒肉店：客單 $600–$1200，昏暗擁擠，聚餐才去。
- 平價小火鍋（如石二鍋、這一鍋平價線）：客單 $200–$300，風味平淡，缺乏差異化。

### 2.2 我們的切入角度：降維打擊

**「用韓食的風味差異化 × 平價火鍋的營運效率」**，創造第三條路。

| 對標對手 | 對方弱點 | 我方武器 |
|---|---|---|
| 傳統韓式燒肉 | 高客單、低頻次、空間老派 | 平價切入、日常高頻、明亮空間 |
| 台式平價火鍋 | 風味同質、缺少儀式感 | 黃銅器皿、愛馬仕橘視覺、韓式靈魂 |
| 韓式湯飯小店 | 衛生感弱、難連鎖 | 模組化中央廚房、連鎖 SOP |

### 2.3 核心戰略句 (Strategic Statement)

> **將韓食從「低頻高客單的聚餐選擇」，轉變為「高頻平價的日常剛需」。**

### 3.1 色彩哲學 (Color Philosophy)

我們採用「**強對比雙主色 + 高級輔助色**」的色彩結構。
這不是裝飾，這是**戰略武器**——用色彩本身告訴消費者：
「我們比你想像中的平價火鍋，更高級一個層次。」

---

### 3.2 品牌主色｜Primary Color

#### 🟠 愛馬仕橘 Hansik Orange

| 項目 | 規格 |
|---|---|
| **中文名** | 愛馬仕橘 |
| **英文名** | Hansik Orange |
| **HEX** | `#F37021` |
| **RGB** | R243 / G112 / B33 |
| **CMYK** | C0 / M67 / Y92 / K0 |

**象徵意義：**
- 韓食的熱辣、食慾激發（大醬、辣醬、泡菜的視覺通感）
- 品牌年輕活潑的爆發力
- 精品級的辨識度（借勢愛馬仕的高級聯想，降維打擊平價火鍋市場）

**使用規則：**

- 使用佔比建議：**50–60%**。
- 絕不與紅色、深褐色、土黃色並用（會回到傳統韓式燒肉店的老派調性）。

## 4. 空間與體驗指南 (Space & Experience)

### 4.1 設計總綱

> **「明亮輕工業風 × 年輕化 × 乾淨衛生」**
>
> 我們要讓消費者一走進門就感受到：「這不是我媽帶我去過的那種韓式店。」

### 4.2 空間設計鐵律

| 規範 | 說明 |
|---|---|
| **照度** | 座位區 ≥ 500 lux，廚房 ≥ 750 lux。**徹底捨棄昏黃燈光**。 |
| **色調** | 主牆：純淨白 + 水泥裸露；地板：仿大理石灰或淺木紋。 |
| **座位** | 2 人桌 70%、4 人桌 25%、6 人以上 5%（對應高頻日常客）。 |
| **動線** | 點餐 Kiosk → 自助吧 → 座位 → 出餐口 → 結帳，單向不回頭。 |
| **氣味** | 強制安裝高效抽風，室內不得殘留烤肉油煙味。 |
| **音樂** | 韓系 City Pop、Indie（如 DEAN、Crush），音量 60–65 分貝。 |

### 4.3 器皿儀式感 (Tableware Ritual)

**用極低成本，創造強大的異國儀式感。**

| 器皿 | 規格 | 採購策略 |
|---|---|---|
| **黃銅色個人小鍋** | 14cm 單柄，霧面仿黃銅鍍層 | 中央採購，單價 $80 以內 |
| **金色扁平筷子** | 韓式不鏽鋼扁筷，18cm | 中央採購，單雙 $15 |
| **長柄湯匙** | 韓式長柄勺，20cm | 同上，單支 $12 |
| **主鍋盛器** | 石鍋或仿石紋厚陶鍋 | 湯飯類專用 |
| **小菜盤** | 純白小圓碟 6cm | 一人 3–4 小碟，呼應「微型自助吧」 |

**鐵律：** 不使用美耐皿、不使用彩色塑膠、不使用印花碗盤。

### 4.4 桌面配置

- **隱藏式抽屜**：餐具、紙巾、沾醬碟收納於桌下抽屜，桌面保持極簡。
- **QR Code 立牌**：亞克力透明立牌，深海藍印刷，放置桌面右上角。
- **桌面禁止物**：醬料瓶罐、DM 傳單、廣告立牌、調味料籃。

## 5. 核心菜單與定價結構 (Product & Price Architecture)

### 5.1 定價邏輯

採雙軌定價：**主食帶來客數，鍋物做利潤。**

| 類別 | 價格帶 | 戰略角色 | 毛利率目標 |
|---|---|---|---|
| **主食類 Bibimbap / Rice** | **$110 – $140** | 引流、衝高迴轉率、午餐主力 | 55–60% |
| **鍋物類 Soups / Hotpots** | **$180 – $260** | 核心利潤來源、晚餐主力、打卡主力 | 65–72% |
| **升級碳水** | $40 – $60 | 客單提升 | 70%+ |
| **飲品** | $40 – $80 | 高毛利附加 | 75%+ |

### 5.2 菜單矩陣建議

#### 🍚 主食類（Bibimbap / Rice） $110–$140
- 韓式石鍋拌飯（經典）
- 辣炒豬肉拌飯
- 部隊鍋拌飯（差異化招牌）
- 起司泡菜拌飯

#### 🍲 鍋物類（Soups / Hotpots） $180–$260
- 泡菜豬肉鍋 $180
- 大醬豆腐鍋 $180
- 部隊鍋（單人份） $220
- 海鮮豆腐鍋 $240
- **★ 馬鈴薯排骨湯 $260（打卡爆品，見第 7 章）**

#### 🍜 升級碳水（Carb Upgrade） $40–$60
- 韓式海苔芝麻拌飯 $40
- 辣炒年糕 $60
- 韓式冬粉 $50

### 5.3 食材模組化原則 (Modular Ingredient Rule)

**為未來連鎖加盟與中央廚房管理，所有食材必須遵守共用率原則。**

| 共用食材 | 應用品項 |
|---|---|
| 節瓜 | 拌飯、大醬鍋、海鮮鍋 |
| 豆芽 | 拌飯、泡菜鍋、部隊鍋 |
| 泡菜 | 所有鍋物、拌飯、小菜、炸雞配料 |
| 板豆腐 | 大醬鍋、部隊鍋、海鮮鍋 |
| 豬五花 | 泡菜鍋、部隊鍋、拌飯 |

**鐵律：** 任何新品開發，核心食材 ≥ 70% 必須與現有菜單重疊。

### 5.4 微型韓式自助吧 (Mini Banchan Bar)

**嚴禁傳統韓式店「10 幾種小菜無限續加」的模式。**

只提供 **5–6 款**易保存、風味穩定的核心小菜：

| 小菜 | 角色 |
|---|---|
| 韓式泡菜 | 靈魂 |
| 醃黃蘿蔔 | 解膩 |
| 涼拌海帶芽 | 清爽 |
| 涼拌豆芽 | 口感 |
| 韓式海苔 | 可做拌飯升級 |
| （季節款） | 每季輪替一款 |

## 6. 營運鐵律 (Operational Bible)

### 🚫 禁止事項（違反即營運事故）

1. **嚴禁**提供超過 6 款小菜的自助吧。
2. **嚴禁**桌邊服務（接單、送餐、結帳由系統與出餐口完成）。
3. **嚴禁**桌上放置調味料罐、DM、立牌廣告。
4. **嚴禁**使用非指定器皿（違反視覺識別）。
5. **嚴禁**菜單上出現非模組化食材的單品（食材共用率 <70%）。
6. **嚴禁**使用「紅色」任何視覺元素（招牌、制服、包材）。

### ✅ 必須執行

1. **必須**導入 Kiosk 自助點餐機（進門第一動線）。
2. **必須**提供 QR Code 桌邊掃碼點餐（作為 Kiosk 備援）。
3. **必須**設置隱藏式桌面抽屜，收納紙巾與餐具。
4. **必須**所有鍋物使用黃銅色個人小鍋。
5. **必須**導入中央廚房統一配送醬料與泡菜（確保風味一致）。
6. **必須**每日開店前拍攝門市清潔照上傳總部雲端。

### 6.1 人力配置原則

| 時段 | 前場 | 後場 | 備註 |
|---|---|---|---|
| 平日午餐 11:30–14:00 | 2 | 3 | 高迴轉，主推主食 |
| 平日晚餐 17:30–21:00 | 2 | 3 | 主推鍋物、客單高 |
| 假日 | 3 | 4 | 加派一名外場引導動線 |

**核心目標：坪效人效對標「平價小火鍋」，風味體驗對標「韓式中高端」。**

## 7. 行銷與爆發力操作規範 (Marketing Playbook)

### 7.1 視覺裂變策略 (Visual Virality)

#### ★ 核心武器：馬鈴薯排骨湯 $260

**視覺鐵則：**
- 排骨**肉山堆疊必須高出鍋緣至少 8 公分**。
- 出餐前由店員當場撒上芝麻與蔥花，製造「儀式感瞬間」。
- 桌面配置黃銅小鍋 + 金色筷子 + 純淨白桌面，構成最佳拍照背景。

**操作 SOP：**
1. 店員上菜時固定站位（背對主牆面）。
2. 提醒顧客：「這道適合拍照喔，要不要幫您拍？」
3. 鼓勵顧客標註 `@韓食日常鍋物` 與 `#肉山挑戰`。

**KPI：** 每月社群自然打卡貼文 ≥ 300 則。

### 7.2 極致壽星行銷 (Birthday Bomb)

**捨棄：** 無感的「壽星九折」「壽星送小菜」。

**採用：**
- 當月壽星憑證件：**贈送特製韓式半半炸雞（市價 $280）**。
- 或升級方案：**任一鍋物肉量激增 +50%**。

**戰略邏輯：**
- 低邊際成本（炸雞食材成本 <$60，肉量加成成本 <$40）。
- 高感知價值（市價 $280 的贈品）。
- **強迫帶動 3–4 人團體聚餐**（壽星不會自己來吃炸雞）。

**KPI：** 壽星活動帶動的客數佔比 ≥ 15%。

### 7.3 社群操作規範

| 平台 | 角色 | 發文頻率 | 主視覺色 |
|---|---|---|---|
| **Instagram** | 主力打卡、視覺放大 | 每週 4–5 則 | 愛馬仕橘主導 |
