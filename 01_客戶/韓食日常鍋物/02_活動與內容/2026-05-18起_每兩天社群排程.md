## 固定規則

- 內容都圍繞品牌：日常韓食、價格日常、韓式鍋物、拌飯、小菜、套餐感、下班後一鍋。
- 所有最終社群視覺必須由 GPT Image 2 製作。
- 所有 FB / IG 動態共用圖一律做成 1080x1350（4:5）。
- 產品圖只能作為 GPT Image 2 的參考素材，不直接當最終社群圖。
- 每篇都要有文案、GPT Image 2 視覺指令、參考產品圖、發布狀態與成效追蹤狀態。
- 若較早貼文因 Meta 憑證或手動發布尚未完成，但內容已進佇列，不阻塞後續一週三更內容製作。
- 在 Meta System User token 完成前，不主動呼叫 Meta 發布，只建立手動發文包與待發布佇列。
- 不做未確認優惠、不承諾價格以外的活動條件。
- IG 同步發布前，圖片需另存或輸出為符合 IG API 的公開圖片 URL；不能只用本機檔案路徑。
