# 2026-05-16 FB 兩篇發文啟動包

客戶：韓食日常鍋物  
平台：Facebook 粉專  
目標 Page ID：`1082884688247950`  
任務：菜單、LINE 好友分成兩篇獨立貼文發布

## 1. 開 token 產生網址

Meta Graph API Explorer：  
https://developers.facebook.com/tools/explorer/

Access Token Debugger：  
https://developers.facebook.com/tools/debug/accesstoken/

Meta Developer App 後台：  
https://developers.facebook.com/apps/

## 2. Graph API Explorer 權限

產生 token 時，至少確認有這些權限：

- `pages_show_list`
- `pages_read_engagement`
- `pages_manage_posts`
- `business_management`

如果 `me/accounts` 找不到韓食日常鍋物粉專，通常是少了 `business_management`。

## 3. 取得 Page token

在 Graph API Explorer 測：

```text
me/accounts?fields=id,name,access_token&limit=100
```

找到 Page ID：

```text
1082884688247950
```

複製該粉專回傳的 `access_token`，這個才是 Page access token。

## 4. 寫入本機 token

在終端機執行：

```sh
"/Users/chenjinting/Desktop/Ewalk.ai 自動化系統/Ewalk.ai Brain/腳本/meta-facebook/set-page-token.command"
```

貼上 Page access token 後按 Enter。輸入時畫面不會顯示 token。

## 8. 成功後記錄

成功時工具會回傳：

- `Meta Photo ID`
- `Meta Post ID`

請把兩篇的 `Meta Post ID` 補回發文紀錄，後續可做 24 小時與 72 小時成效追蹤。

## 9. 風險提醒

- 不要把 access token 貼到聊天、Obsidian、公開文件或截圖裡。
- 若出現 `Session has expired`，代表 token 過期，需要回 Graph API Explorer 重產。
- 若出現權限錯誤，先確認 token 是 Page token，不是 User token。
- 兩篇要分開執行，不能把兩張圖放在同一個指令裡。
