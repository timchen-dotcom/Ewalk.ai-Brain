# 韓食日常鍋物｜五星評論送小菜 DM 需求稿

建立日期：2026-05-05
狀態：待設計
用途：Google 五星評論導流 / 店內轉換物料

## 任務摘要

製作一張「五星評論送小菜」DM，鼓勵顧客用餐後留下 Google 五星評論，現場回饋一份小菜。

## 使用場景

- 櫃台結帳提醒
- 出餐口提醒
- 店員口頭引導後出示
- IG 限動或 LINE OA 圖文
- Google 商家評論 QR Code 旁輔助說明

注意：品牌規範中不建議桌上長期放置 DM 或立牌，避免破壞乾淨桌面感。若要店內使用，建議放在櫃台、出餐口或由店員短暫出示。

## 主標文案

### 版本 A

五星好評，請你吃韓式小菜

### 版本 B

留下 5 星評論，招待你一份今日小菜

### 版本 C

喜歡今天這鍋嗎？給我們 5 星，送你一份小菜

## 建議採用文案

五星好評，請你吃韓式小菜

## 副標文案

掃描 QR Code 到 Google 留下 5 星評論，出示畫面給店員，即可兌換一份指定小菜。

## 小字規則

- 每桌 / 每人兌換規則待確認
- 小菜品項以現場供應為準
- 優惠不可折抵現金
- 活動期間與兌換限制依門市公告為準

## DM 資訊架構

1. 品牌 Logo
2. 主標：五星好評，請你吃韓式小菜
3. QR Code 區塊：放 Google 商家評論連結
4. 操作步驟：
   - 掃描 QR Code
   - 留下 5 星評論
   - 出示評論畫面
   - 兌換今日小菜
5. 小字活動規則

## 視覺方向

- 主色：Hansik Orange `#F37021`
- 對比色：Hansik Deep Blue `#0B2545`
- 背景：白色或乾淨淺底
- 風格：現代、乾淨、年輕、食慾感，不走傳統韓式紅色或老派燒肉店風格
- 圖像元素：小菜圓碟、泡菜、黃蘿蔔、海帶芽、豆芽擇一，不要做成雜亂小菜拼盤

## 建議尺寸

- 店內印刷：A5 直式
- 社群貼文：1080 x 1350 px
- 限動：1080 x 1920 px
