## 一句話判斷

這三條線都不是單純賣洗護產品，而是在賣「染燙後髮質問題的解決場景」：

- Curly Plus：讓自然捲、波浪捲、燙後捲髮回到彈、亮、輕盈、不毛躁。
- Keratin：針對染燙漂後的乾、脆、毛躁、容易斷裂，主打重建、柔順、光澤。
- Color Perfect：針對染後掉色、暗沉、失去光澤，主打護色、亮澤、色彩持久。

圖像策略上要避免「通用洗髮精形象圖」，應該讓每張圖都對應到一個明確痛點與一個可視化結果。

## 產品線拆解

### Curly Plus｜捲髮保濕定義系列

目標受眾：

- 自然捲、波浪髮、燙後捲髮使用者。
- 困擾是毛躁、捲度鬆散、乾澀、缺乏彈性、整理後容易塌。

官方功能重點：

- Curl Shampoo：為捲髮、波浪髮與燙後髮設計，溫和清潔並帶來保濕、光澤、彈性；主打抗毛躁、讓捲度柔軟輕盈。
- Curl Mask：保濕髮膜，幫助梳理、滋養、抗毛躁，讓捲度更有定義與彈性。
- Curl Mousse：無瓦斯慕斯，定義與保濕捲髮，形成隱形保護屏障，抗環境傷害與毛躁，不厚重。
- 成分語言：ceramides、moringa，可轉譯成「髮絲屏障」、「植物修護」、「彈潤保濕」。

圖像方向：

- 主視覺：濕潤光澤的立體捲髮近景，髮絲有彈性和空氣感，產品站在前景。
- 痛點圖：左側毛躁蓬亂、右側彈潤成束；不做誇張醫美式 before/after。
- 成分圖：辣木葉、陶瓷光澤屏障、透明水滴，用來表達保濕與保護。
- 使用流程圖：髮浴清潔 -> 髮膜滋養 -> 慕斯定型。
- 結果圖：捲度成束、輕盈、不黏、不塌。

可用標語方向：

- 「捲度回彈，毛躁收服」
- 「讓捲髮有形，也有光」
- 「洗、護、塑，一次完成捲髮日常」

避免：

- 不要把捲髮拍成厚重油亮。
- 不要用直髮模特作為主結果。
- 不要把慕斯做成硬梆梆定型感。

### Keratin｜角蛋白重建修護系列

目標受眾：

- 經常染、燙、漂、拉直或化學處理後髮質受損者。
- 困擾是乾、脆、毛躁、打結、無光澤、容易斷裂。

GLAMOUROLOGY 上架品項：

- 角蛋白重建髮浴 300ml
- 角蛋白重建髮膜 100ml
- 角蛋白重建髮膜 500ml
- 角蛋白重建髮浴 100ml

官方功能重點：

- Restructuring Shampoo：針對受處理、脆弱、營養不足且常做化學處理的頭髮，主打深層保濕滋養、抗毛躁、馴服髮絲、含 Keratin。
- Restructuring Mask：針對受處理、脆弱、營養不足髮質，主打梳理、抗毛躁、柔軟與控制；描述中提到 Keratin 技術協助深層保濕，並帶來髮絲強韌與柔順。
- 成分語言：Keratin、Milk Protein、Bamboo Extract，可轉譯成「蛋白補給」、「竹萃保濕」、「髮芯重建感」。

圖像方向：

- 主視覺：乾枯髮絲轉成柔順亮澤髮束，產品位於畫面中心，背景可用白、奶金、柔霧光。
- 痛點圖：染燙漂後的毛躁、斷裂、打結，用髮絲微距呈現。
- 成分圖：角蛋白微粒、牛奶蛋白光帶、竹葉水感，強化「重建與滋養」。
- 機制圖：髮絲毛鱗片打開 -> 補充蛋白與水分 -> 表面平滑有光。
- 結果圖：柔順、服貼、好梳、光澤。

可用標語方向：

- 「染燙後的乾脆毛躁，交給角蛋白重建」
- 「洗後柔順，護後有光」
- 「為受損髮補回強韌與柔亮」

避免：

- 不要宣稱醫療或永久修復。
- 不要畫成頭皮治療或生髮效果。
- 不要只用水花，需讓「受損修護」被看見。

### Color Perfect｜紅鑽完美護色系列

目標受眾：

- 染髮後想延長髮色漂亮狀態的人。
- 困擾是洗幾次後褪色、髮色暗沉、光澤下降、染後髮絲乾澀。

GLAMOUROLOGY 上架品項：

- 紅鑽完美護色髮浴 1000ml／300ml
- 紅鑽完美護色髮膜 1000ml／250ml
- 紅鑽鎖色噴霧 200ml
- 紅鑽璀璨果油噴霧 150ml
- 多種髮浴與髮膜組合包

官方功能重點：

- Color Perfect Shampoo：Red Algae 與 Sodium Gluconate 配方；防止髮色隨時間褪色，讓髮絲柔軟有光、不厚重；標示 vegan、silicone-free、SLS/SLES-free。
- Color Perfect Mask：Red Algae 與 Sodium Gluconate；滋養並封存髮色、保護髮纖維；髮絲呈現絲滑、亮澤、好梳。
- Color Protection Spray：穩定髮色、增加持久度與強度，讓染後髮色更持久、更有強度；vegan、silicone-free、sulphate-free。
- Color Perfect Serum／Conditioner：以 Gold、Diamond、Ruby 做為光澤與色調完美化的高級成分語言；適合轉成「紅鑽光澤」、「冷暖色調都能被提亮」的視覺。

圖像方向：

- 主視覺：紅鑽、紅藻、彩色髮束與鏡面光澤，產品置中，紅色要高級不能廉價。
- 痛點圖：染後髮色從飽和變暗沉、洗後褪色；用色卡或髮束階段圖呈現。
- 成分圖：紅藻、水感礦物、Sodium Gluconate 可用「鎖色防護網」呈現。
- 光澤圖：金、鑽、紅寶石光點搭配髮絲反光，表達亮澤與色彩精緻度。
- 組合圖：洗髮 -> 髮膜 -> 鎖色噴霧 -> 果油噴霧，對應「洗護鎖亮」完整路徑。

可用標語方向：

- 「染後漂亮髮色，不只停留在剛染完」
- 「鎖住色彩，也鎖住光」
- 「紅鑽護色，讓髮色更亮、更久、更柔順」

避免：

- 不要暗示產品可以直接染色或改變髮色。
- 不要把護色效果做成誇張永久不褪色。
- 紅色視覺要偏精品寶石感，不要像年節促銷或廉價彩妝。

## 銷售頁建議圖像模組

以下模組可套用三條產品線，只需替換主色、髮絲狀態與成分語言：

1. 首屏 Hero  
   產品合照 + 髮絲結果 + 一句主張。目標是在 3 秒內讓使用者知道這條線解決什麼問題。

2. 痛點共鳴圖  
   用 3-4 個問題卡呈現：毛躁、乾澀、褪色、打結、捲度鬆散。每張卡要有真實髮絲情境。

3. 成分與技術圖  
   Curly Plus 用辣木、神經醯胺、保濕屏障；Keratin 用角蛋白、牛奶蛋白、竹萃；Color Perfect 用紅藻、Sodium Gluconate、紅鑽光澤。

4. 使用流程圖  
   以產品順序視覺化，不要只列文字。電商頁可用「洗 -> 護 -> 鎖／塑」的橫向流程。

5. 結果感圖  
   一張大圖只講一種結果：彈潤、柔順、護色、亮澤、輕盈。不要一張塞太多賣點。

6. 組合包購買圖  
   商品規格與組合包要用乾淨商品陳列，搭配簡短購買理由：入門、回購、大容量、旅行。

7. 安心與質感圖  
   可放 vegan、silicone-free、SLS/SLES-free 等官方可驗證資訊；若台灣頁面沒有明確標示，應以官方來源確認後再放。
