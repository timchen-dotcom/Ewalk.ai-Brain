# 幻色鏡方美業控股集團

## 客戶定位

幻色鏡方美業控股集團是 Ewalk.ai 的重要客戶。Ewalk.ai 的目標是成為幻色鏡方的 AI 大腦，承接其 AI、資料、教育、行銷與品牌系統建置。

## 集團品牌架構

### 事業體

- STAR Color
- STAR SPA

### 關係品牌

- 尤拿 UNA
- HIVE

### 髮品品牌

- Qinran

### 教育與系統核心

- 大美好學院
- 學習護照系統
- AI 染髮師培訓
- 微型教育系統

## Ewalk.ai 的角色

Ewalk.ai 不是單純代操行銷，而是幻色鏡方的 AI 大腦：

- 建立集團資料中樞
- 建立品牌知識庫
- 建立 AI 行銷與設計流程
- 建立教育系統與學習護照
- 建立加盟資料與營運模型
- 建立跨品牌資料整合與決策輔助
