# 服務內容調整｜嘉昱 3+2 夏季汽車隔熱膜快打

## 方案摘要

本案調整為：

- 行銷服務費：NT$30,000
- 廣告投放費：NT$20,000
- 合計：NT$50,000

定位從「最低可跑的快打方案」調整為「夏季汽車隔熱膜詢問驗證包」。重點是用 3 到 4 週，測出哪些痛點、素材與文案能帶來有效詢問與預約。

| 模組 | 交付內容 | 數量／範圍 |
| --- | --- | --- |
| 快打策略整理 | 活動主軸、目標客群、廣告角度、導流路徑、預算配置 | 1 份 |
| 夏季優惠素材包 | 「夏季汽車隔熱膜健檢」主軸，延伸車內爆熱、舊膜退化、選膜專業 3 個方向 | 3 組 |
| 廣告圖卡內容 | 廣告圖卡文字、版型方向、素材需求與 CTA | 3 張圖卡方向 |
| 社群貼文 | FB／IG 貼文文案，搭配夏季健檢、舊膜提醒、選膜專業、預算優先順序 | 4 則 |

| 預算 | 用途 | 說明 |
| ---: | --- | --- |
| NT$14,000 | 私訊／LINE 詢問導流 | 主力投放，測試車內爆熱與舊膜健檢需求 |
| NT$4,000 | 在地互動與信任素材放大 | 放大店家專業感、建翰師傅說明、案例或 Google 評論 |

## 修改次數

- 文案修改：1 輪。
- 圖卡文字與版型方向修改：1 輪。
- 廣告上線後依數據做 1 輪調整建議。

## 客戶需提供

- 正式店名、地址、電話、營業時間。
- 導流入口：Messenger、LINE 或電話。
- Meta 粉專、商業管理平台與廣告帳戶授權。
- LINE 官方帳號連結、好友加入網址／QR Code、管理權限或現有設定截圖。
- 可公開使用的店面照、施工照、膜材照、舊膜案例或建翰師傅照片。
- 是否可使用建翰師傅肖像與聲音。
- 客戶提供的短影音腳本庫或過往腳本參考。

## 不包含

- 多日拍攝。
- 大量短影音剪輯。
- 完整月代營運。
- 官網或 Landing Page。
- 客戶私訊代回。
- LINE 官方帳號長期代營運、代回訊息、API 串接、會員／CRM 串接與付費訊息費用。
- 保證成交數。
- 建築隔熱膜年度 IP 策略全案。
- 未列於本服務內容的追加素材或活動頁。

## 阿順建議

這版服務內容比原本 2+1 更合理。服務費 3 萬可以支撐素材、文案、設定、檢查與回報；廣告費 2 萬也比較能測出有效詢問成本。重點是不要把它包成「月代營運」，而是清楚定義為「夏季詢問驗證包」。
