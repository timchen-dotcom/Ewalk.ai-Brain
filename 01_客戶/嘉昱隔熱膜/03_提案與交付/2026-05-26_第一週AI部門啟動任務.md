# 嘉昱隔熱膜第一週 AI 部門啟動任務

週期：2026-05-26 到 2026-05-29
主管：阿順
狀態：待提姆先生確認啟動

## 本週目標

建立嘉昱隔熱膜的第一版客戶資料、建築隔熱膜專家 IP 定位、附件資料整理與第一批內容方向。這週先不急著對外發布，而是把「能不能成為專家 IP」的基礎材料補齊。

## 已啟動部門

| 部門 | 角色 | 本週任務 |
| --- | --- | --- |
| 客戶成功與策略部 | 客戶成功經理 | 補齊正式店名、窗口、服務範圍、報價規則與案例素材 |
| 品牌策略部 | IP 策略企劃 | 確認建翰師傅的人設、IP 名稱、定位與第一階段內容主軸 |
| 市場洞察部 | 市場研究員 | 整理附件市場資料，查證補助與競品內容 |
| 社群內容部 | 社群主編 | 建立內容支柱、第一月題庫與短影音腳本方向 |
| 視覺設計部 | 設計企劃 | 規劃熱顯像、溫度對比、材料分層、施工流程的視覺模板 |
| 廣告投放部 | 廣告投放專員 | 判斷是否可做住宅／社區／商辦三種導流廣告 |
| 數據報表部 | 數據分析師 | 建立詢價來源、客群類型、窗戶問題與成交追蹤欄位 |
| 專案管理部 | 專案助理 | 排定待補資料、素材收件與提姆先生需確認事項 |

## 需要提姆先生確認

- [ ] 是否確定以「建築隔熱膜／建築包膜專家」作為主定位。
- [ ] IP 名稱是否先採「嘉昱隔熱研究所」或「建翰師傅隔熱研究室」。
- [ ] 建翰師傅可出鏡的頻率、語氣與可談內容。
- [ ] 是否可公開談膜材型號、每才價格區間、保固與案例。
- [ ] 是否同步做 Google 商家、YouTube 與短影音。
- [ ] 是否預計做廣告導流與每月預算。

## 待客戶補資料

- [ ] 正式店名、LOGO、店面照片。
- [ ] 建築膜產品線、規格表、保固文件。
- [ ] 最近 10 組建築施工案例照片或影片。
- [ ] 建翰師傅與施工過程可拍攝範圍、不可公開畫面。
- [ ] 常見客戶問題與成交話術。
- [ ] 報價規則：每才單價、最低施工費、特殊施工條件。
- [ ] 目前是否有 LINE OA、網站、表單、Google 商家後台權限。

## 阿順下一步

1. 等提姆先生確認 IP 名稱與建翰師傅出鏡方向。
2. 依確認結果建立第一月內容月曆。

4. 若客戶能提供案例素材，優先做「實測案例」系列。
5. 若客戶要攻社區與商辦，建立現勘報告模板與 B2B 提案簡報。
