# LINE 官方優化建議｜嘉昱夏季汽車隔熱膜快打

用途：讓本次 Meta 廣告若導流到 LINE OA 時，使用者加入後能快速知道怎麼詢問、怎麼預約、要提供哪些資訊，降低詢問流失。

## 優化範圍

| 項目 | 優化內容 | 狀態 |
| --- | --- | --- |
| 基本資料 | 店名、地址、電話、營業時間、服務項目、地圖連結檢查 | 待 LINE OA 資料 |
| 歡迎訊息 | 加入好友後立即引導使用者提供車型、需求、預算與預約時段 | 初稿完成 |
| 關鍵字回覆 | 設定隔熱膜、價格、預約、地址、營業時間、舊膜等常見關鍵字方向 | 初稿完成 |
| 詢問導流話術 | 把廣告私訊與 LINE 詢問導到同一套接單流程 | 初稿完成 |
| 圖文選單方向 | 規劃 4 到 6 個按鈕文字與功能方向 | 初稿完成 |

## 歡迎訊息建議

建翰師傅您好，有客人加入 LINE 後，建議第一則訊息不要太長，直接讓對方知道下一步。

```text
您好，這裡是嘉昱汽車／建築隔熱膜。

如果想詢問汽車隔熱膜，請先回覆：
1. 車型／年份
2. 想貼前擋、車身、全車或天窗
3. 目前是否有舊膜、起泡、退色或隔熱變差
4. 希望預約的日期或時段

建翰師傅會依照您的需求協助評估適合的隔熱膜方案。
```

## 關鍵字回覆方向

| 關鍵字 | 回覆方向 |
| --- | --- |
| 價格／報價 | 請客人提供車型、施工範圍與是否有舊膜，再由店內評估 |
| 預約 | 詢問希望日期、時段、車型與施工項目 |
| 地址 | 回覆中華北店地址、地圖連結與停車提醒 |
| 營業時間 | 回覆營業時間與建議預約說法 |
| 前擋 | 說明前擋隔熱膜需兼顧隔熱、清晰度、夜間視線 |
| 全車 | 引導提供車型與預算，方便建議完整搭配 |
| 舊膜 | 詢問是否起泡、退色、霧化、殘膠，提醒需現場評估 |
| 建築隔熱膜 | 引導提供玻璃尺寸、場域、日曬方向與想改善問題 |

## 圖文選單方向

| 按鈕 | 建議文字 | 功能 |
| --- | --- | --- |
| 1 | 汽車隔熱膜詢問 | 開啟車型、需求、預算詢問話術 |
| 2 | 夏季隔熱膜健檢 | 導到本次活動主軸 |
| 3 | 建築隔熱膜詢問 | 收集玻璃尺寸、場域與日曬問題 |
| 4 | 查看地址 | 開啟 Google 地圖或店家地址 |
| 5 | 預約施工 | 詢問日期、時段、車型 |
| 6 | 看案例 | 導到 FB、IG、Google 商家或相簿 |

## 需要嘉昱提供

- LINE OA 連結或好友加入網址／QR Code。
- LINE OA 管理權限，或目前基本資料、歡迎訊息、關鍵字回覆、圖文選單截圖。
- 正式店名、地址、電話、營業時間。
- 是否希望 LINE 主推汽車隔熱膜、建築隔熱膜，或兩者都放。
- 可公開的案例連結、Google 商家連結或社群相簿。

## 不包含

- LINE API 串接。
- 會員系統、CRM、點數或自動化分眾串接。
- LINE 官方帳號長期代營運。
- 客戶訊息代回。
- LINE 付費訊息費用。

## 阿順判斷

這項放進 3+2 方案是合理的，因為廣告若導流到 LINE，第一時間的歡迎訊息與關鍵字回覆會直接影響有效詢問率。範圍要守在「導流與基本優化」，不要變成客服代營運或系統開發。
