## 素材測試矩陣

| 變體 | 文案角度 | 素材 | CTA |
| --- | --- | --- | --- |
| A1 | 車內爆熱 | 方向盤／溫度計／陽光照車內 | 傳車型初步判斷 |

## 預算調整規則

第 3 到 5 天初步判斷：

| 狀況 | 動作 |
| --- | --- |
| 某素材私訊成本明顯低 | 將預算轉到該素材 |
| 詢問多但無效 | 調整文案，加上車型、預算、預約 CTA |
| 互動高但私訊少 | 改強 CTA，加入「傳車型」 |
| 廣告消耗慢 | 放寬受眾或改素材 |
| 私訊品質好但量少 | 小幅加碼或延長投放 |

## 每日檢查

- [ ] 廣告是否正常消耗。
- [ ] 私訊是否有人回覆。
- [ ] 有效詢問與無效詢問比例。
- [ ] 哪一組文案帶來最多車型資訊。
- [ ] 是否有重複問題可補到貼文或 Q&A。
- [ ] 是否需要暫停無效素材。

## 上線前必查

- [ ] 粉專名稱與商家資訊正確。
- [ ] 廣告導流方式正確。
- [ ] 素材無未遮車牌或敏感資訊。
- [ ] 文字未承諾固定降溫數字。
- [ ] 未使用未確認價格或優惠。
- [ ] 建翰師傅肖像可使用。
- [ ] 廣告費支付方式已確認。
