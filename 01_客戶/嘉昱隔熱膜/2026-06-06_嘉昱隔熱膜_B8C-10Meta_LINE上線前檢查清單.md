# 嘉昱隔熱膜 B8C-10 Meta / LINE 上線前檢查清單

## 一句話結論

B8C-10 是嘉昱正式廣告上線前的人工驗證清單，用來確認 LINE 導流、Meta 權限、付款方式、Google 商家資訊、AI 素材審稿與客服流程是否補齊；本文件不是上線批准，不可直接啟動廣告、發文、寫 Firebase 或消耗預算。

## 目前判定

| 項目 | 判定 | 說明 |
| --- | --- | --- |
| 是否可做內部檢查 | Go | 可用人工方式逐項確認 LINE、Meta、Google 商家與素材審稿狀態。 |
| 是否可讓 OpenClaw / Ollama 協助整理 | Go, low-risk | 僅限人工貼入檢查結果後做摘要、分類、待辦與風險判斷。 |
| 是否可登入外部後台操作 | 需批准 | Meta、LINE、Google 商家或廣告帳戶屬正式外部系統，任何登入操作都需提姆先生明確批准。 |
| 是否可正式投放 | No-Go | 權限、付款、導流、客服與審稿尚未全部完成。 |
| 是否可消耗 NT$20,000 廣告費 | No-Go | 提姆先生尚未批准正式投放。 |

## 檢查邊界

可做：

- 依人工回報結果更新檢查清單。
- 整理缺件、風險、待辦與需批准事項。
- 產出給提姆先生審核的 Go / Conditional Go / No-Go 判定。
- 讓 Mac Studio / OpenClaw 依本文件做低風險文字回報。

不可做：

- 不自動登入 Meta、LINE、Google 商家或任何正式外部後台。
- 不啟動廣告、不建立正式 Campaign、不調整預算。
- 不發文、不排程貼文、不修改粉專資訊。
- 不寫入 Firebase 或其他正式系統。
- 不把 AI 素材直接視為客戶已批准素材。
