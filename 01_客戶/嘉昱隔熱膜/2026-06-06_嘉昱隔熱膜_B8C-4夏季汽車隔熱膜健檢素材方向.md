# 嘉昱隔熱膜 B8C-4 夏季汽車隔熱膜健檢素材方向

## 一句話結論

嘉昱第一波素材應先用「夏季汽車隔熱膜健檢」降低詢問門檻，不直接承諾折扣、降溫幅度或成交結果。素材方向主打車內爆熱、舊膜退化、選膜專業與預算優先順序，等客戶補齊素材授權與導流資訊後再定稿。

## 素材策略

| 項目 | 判斷 |
| --- | --- |
| 活動名稱 | 嘉昱夏季汽車隔熱膜健檢 |
| 第一波目的 | 帶出私訊詢問與到店預約 |
| 核心 CTA | 傳車型、傳舊膜照片、描述目前遇到的問題 |
| 不做事項 | 不公開未確認價格、不承諾固定降溫、不保證成交、不使用未授權素材 |
| 素材優先 | 先做 3 張靜態廣告方向與 4 支短影音腳本方向 |
| 可先用 | 店面、膜材、車內高溫情境、施工手部、舊膜案例、建翰師傅說明畫面 |

## 第一波靜態素材方向

### 方向 1｜車內爆熱健檢

用途：

- 拉夏季痛點。
- 讓車主覺得「可以先問，不一定要馬上下單」。

主標：

```text
夏天車內太熱？
```

副標：

```text
先做隔熱膜健檢
```

輔助文案：

```text
傳車型與目前問題，建翰師傅協助初步判斷前擋、車身、天窗搭配方向。
```

畫面需求：

- 車內陽光直射。
- 方向盤或座椅熱感。
- 溫度計或隔熱燈情境。
- 建翰師傅拿膜材樣本說明。

風險提醒：

- 不寫「保證降溫」。
- 不寫「冷氣變強」。
- 不寫未實測的溫度數字。

### 方向 2｜舊膜退化健檢

用途：

- 打中古車、舊車、舊膜起泡與退色客群。
- 引導客戶傳照片初步判斷。

主標：

```text
舊膜起泡、變紫、退色？
```

副標：

```text
隔熱效果可能也退化了
```

輔助文案：

```text
傳舊膜照片，先判斷是否需要局部更換或重新規劃。
```

畫面需求：

- 舊膜起泡近拍。
- 變紫或退色膜。
- 拆膜或施工前後對比。
- 舊膜與新膜比較。

風險提醒：

- 不說「一定要重貼」。
- 不把所有舊膜狀態都講成危險。
- 不公開客戶車牌或個資。

### 方向 3｜選膜專業健檢

用途：

- 建立嘉昱專業感。
- 避免只打價格與折扣。

主標：

```text
隔熱膜不是越黑越好
```

副標：

```text
前擋、車身、天窗要分開搭配
```

輔助文案：

```text
依車型、夜間視線、熱感與預算，協助初步抓方向。
```

畫面需求：

- 不同透光度膜材樣本。
- 前擋、車身、天窗位置示意。
- 建翰師傅指膜材說明。
- 膜材樣品本或展示玻璃。

風險提醒：

- 不說「越貴越好」。
- 不說「某品牌一定最好」。
- 不碰未確認品牌、型號與保固承諾。

### 方向 4｜預算優先順序健檢

用途：

- 降低全車重貼的心理壓力。
- 引導預算有限客戶先詢問。

主標：

```text
預算有限，先做哪裡最有感？
```

副標：

```text
前擋、車身、天窗先抓優先順序
```

輔助文案：

```text
傳車型與預算區間，建翰師傅先幫你判斷最需要處理的位置。
```

畫面需求：

- 車輛前擋、車身、天窗三位置。
- 圖上用簡單標示區分位置。
- 建翰師傅在車旁說明。

風險提醒：

- 不承諾低預算一定能滿足。
- 不公開未確認價格。
- 不做「最低價」訴求。

- 是否採用客戶案例照片。
- 是否進入正式發文或廣告投放。

- 不直接投放廣告。

- 不承諾固定降溫幾度。
- 不寫「保證成交」、「保證有效」、「最低價」。
