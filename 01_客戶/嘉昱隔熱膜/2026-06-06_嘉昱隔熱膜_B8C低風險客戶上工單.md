# 嘉昱隔熱膜 B8C 低風險客戶上工單

## 一句話結論

嘉昱隔熱膜可作為 OpenClaw 第一個低風險客戶上工測試。OpenClaw 已能根據人工貼入文字整理客戶現況、可做事項、需批准事項與禁止事項；接下來由 Codex 主窗口負責審核、補齊既有 Vault 脈絡、落檔與 Git 同步。

本階段只做資料整理與上工準備，不讀接案碟、不發文、不寫 Firebase、不接正式客戶通道、不碰廣告預算或金流。

OpenClaw 可做：

- 依人工貼入文字做摘要。
- 幫忙把工作分成可直接做、需批准、禁止。

OpenClaw 不做：

- 不讀檔。
- 不使用工具。
- 不寫檔。
- 不搜尋網路。
- 不對外發訊息。
- 不接 Meta / Firebase / 客戶通道。

## 需要提姆先生批准

| 事項 | 原因 |
| --- | --- |
| 對客戶發送正式啟動訊息 | 代表 Ewalk.ai 對客戶進入正式執行。 |
| 請嘉昱授權 Meta 粉專、商業管理平台與廣告帳戶 | 涉及正式廣告權限。 |
| 對外文案最終版 | 避免價格、優惠、保固、效果承諾出錯。 |
| 廣告正式上線 | 實際消耗客戶廣告費。 |
| 廣告費代墊或付款方式 | 涉及帳務、憑證與金流。 |
| 預算調整或追加項目 | 超出原 `3+2` 方案邊界。 |
| 正式寫入 Firebase / Command Center | 會改正式系統資料。 |
| 接正式客戶通道 | 會產生外部溝通與承諾風險。 |

## 禁止事項

- 不直接發文。
- 不直接設定或啟動 Meta 廣告。
- 不碰廣告預算、付款方式或金流。
- 不代客戶回覆私訊。
- 不向客戶傳正式訊息。
- 不把草稿當成已核准文案。
- 不把本機 dry-run 寫入 Firebase。
- 不把 OpenClaw 低風險文字能力視為正式操作權限。
- 不承諾固定降溫幾度、補助一定成功、價格一定適用或保證成交。
