## Conditional Go 條件

如果素材不足或改用 AI 素材，但下列條件成立，可以送提姆先生評估 Conditional Go：

- 店家資料、導流入口、Meta 權限、付款方式已完成。
- 客戶同意第一波是測試性投放。
- 客戶同意先使用 AI 素材、店面、膜材、文字圖、施工手部或不露臉素材。
- 文案不公開價格、不承諾降溫、不承諾成交。
- 提姆先生批准素材不足狀態下先小規模測試。

Conditional Go 仍不得自動上線；必須由提姆先生批准。

## No-Go 條件

只要出現以下任一情況，就不能上線：

| No-Go 原因 | 風險 |
| --- | --- |
| 付款方式不明 | 可能誤用公司或客戶金流。 |
| 導流入口不明 | 廣告有花費但客戶不知道去哪裡詢問。 |
| LINE / Messenger 未測試 | 私訊或導流可能失效。 |
| Meta 權限未開 | 無法安全設定或檢查廣告。 |
| 素材授權不明 | 可能使用未授權照片、肖像、車牌或客戶個資。 |
| 價格、保固、優惠未確認 | 可能產生錯誤承諾。 |
| 文案含保證降溫或保證成交 | 合規與客訴風險高。 |
| 廣告費誤用 NT$30,000 | 方案邊界錯誤，應以廣告費 NT$20,000 為準。 |
| 未取得提姆先生上線批准 | 不可對外發布或消耗預算。 |
