# TheVision｜官網重建與定期更新規劃

建立日期：2026-05-26
現有官網：https://www.thevision.tw/
狀態：Preview 已建立

## 任務摘要

提姆希望 TheVision 客戶官網後續重新交由阿順規劃與製作，並由 Ewalk.ai 定期更新。

這個任務不只是改版網站外觀，而是把 TheVision 官網變成可持續營運的內容與轉換入口，包含服務頁、檔期活動、作品案例、Google 商家、SEO 文章與預約導流。

## 現有官網初步觀察

目前官網已具備：

- 首頁品牌介紹
- 關於我們
- 價目表連結
- 聯絡我們
- 隱私政策與無障礙聲明
- 趨勢文章 / 部落格內容
- TheVision 選品區
- Instagram 內容嵌入

公開頁面可見的主軸包含：

- TheVision 美學髮廊
- 高質感沙龍定位
- 透明價格方案
- 商業趨勢 / Fashion Trends
- 淡水在地美學、春夏髮色、燙髮、三倍水光染等方向

## 初步問題

- 官網看起來像內容堆疊，核心轉換路徑不夠集中。
- 服務頁不夠像「可被搜尋、可被預約」的 SEO 頁。
- 檔期活動與服務技術項目需要定期更新，否則官網容易停在一次性上架。
- 作品案例、設計師、Google 商家、社群內容尚未形成完整閉環。
- 價目表目前是外部 Canva 連結，後續可評估是否整合成網站內頁。

## 改版目標

- 建立 TheVision 的正式品牌官網架構
- 讓每個主要服務都有可搜尋的服務頁
- 讓檔期活動可以快速更新
- 讓作品案例與 SEO 文章能持續累積
- 讓 Google 商家、IG、LINE / 預約入口與官網互相導流
- 讓阿順可以依月度工作節奏協助更新

## 建議網站架構

### 1. 首頁

目的：建立品牌印象與預約入口。

內容：

- 品牌主張
- 淡水高質感美學髮廊定位
- 主打服務入口
- 本月檔期
- 精選作品
- 預約 CTA

### 2. 服務頁

每個服務都應該有獨立頁面：

- 三倍水光染
- 春夏流行髮色
- 女生燙髮
- 男士燙髮
- 頭皮護理
- 系統式護髮
- VIP 包套 / 五次修護計畫

每頁固定包含：

- 適合對象
- 解決痛點
- 服務流程
- 價格或價格區間
- 作品案例
- 注意事項
- 預約 CTA
- Google 商家 / FAQ / SEO 關鍵字

### 3. 作品案例

建議分類：

- 染髮作品
- 燙髮作品
- 護髮作品
- 男士造型
- 設計師作品

每個作品應包含：

- 服務項目
- 顧客需求
- 技術重點
- 適合髮況
- 維持建議
- 預約同款 CTA

### 4. 檔期活動

用於每月活動快速更新：

- 本月主推服務
- 新客優惠
- 包套方案
- 季節主題
- 指定設計師活動

### 5. 設計師 / 團隊

可逐步補：

- 設計師介紹
- 擅長項目
- 作品連結
- 預約入口
- IG 連結

### 6. 文章 / SEO

文章方向：

- 淡水染髮推薦
- 淡水燙髮推薦
- 三倍水光染是什麼
- 春夏髮色趨勢
- 護髮包套怎麼選
- 男士燙髮整理方式

### 7. 聯絡與預約

需要明確：

- 地址
- 營業時間
- 電話
- LINE / 預約連結
- Google Maps
- 停車或交通資訊

## 定期更新機制

### 每週更新

- 檢查本週主推檔期是否需要更新
- 補 1-3 則作品案例
- 檢查 Google 商家是否需要新增貼文或產品 / 服務
- 檢查官網 CTA、LINE / 預約連結是否正常

### 每月更新

- 更新本月活動頁
- 整理當月服務主打
- 補一篇 SEO 文章或服務內容
- 更新作品案例分類
- 同步 Google 商家產品 / 服務 / 貼文
- 檢查價目表與優惠是否一致

### 每季更新

- 檢查首頁主視覺與季節主題
- 更新流行趨勢內容
- 檢查服務頁 SEO 表現
- 盤點哪些服務需要新增 FAQ

## 阿順可負責項目

- 官網架構規劃
- 文案與服務頁草稿
- SEO 文章大綱與初稿
- Google 商家更新建議
- 每週 / 每月更新待辦
- 圖像生成需求與 Prompt
- 更新紀錄與版本管理

## 需要提姆或客戶確認

- 官網後台權限
- 是否使用現有 Wix / Webflow / WordPress / 自架網站
- 是否保留既有網域與頁面
- 價目表是否可公開完整放入網站
- 預約系統連結
- 設計師名單與作品授權
- 是否需要正式上線前審稿

## 建議第一階段

先不要直接改正式官網。

第一階段做：

1. 建立新官網架構與 sitemap。
2. 整理首頁文案。
3. 整理 5 個主要服務頁。
4. 整理第一批作品案例格式。
5. 建立定期更新 SOP。
6. 做一個 Preview 版本給提姆與客戶確認。
