# STAR Color｜Suno第一批20首情境歌詞包

## 產製原則

這批歌曲不直接歌頌 STAR Color，而是圍繞可能發生在髮廊、鏡子前、下班路上、人生轉換點的情境。

重點是：

- 文字要有畫面。
- 詞不要太專業、太文謅謅。
- 副歌要好唱、好剪、好記。
- 品牌可以藏在情境裡，不必每首都說出名字。
- 好聽先成立，品牌再被聽見。

## Suno More Options 建議設定

### 通用設定

| 選項 | 建議 | 原因 |
| --- | --- | --- |
| Lyrics Mode | Manual | 這批已經有完整歌詞，不讓 Suno 自動改寫 |
| Vocal Gender | Female 為主 | STAR Color 主要情境偏女性視角、美業服務與生活感 |
| Weirdness | 25%-55% | 品牌歌要好聽、好傳，第一批不要太怪 |
| Style Influence | 65%-85% | 要讓曲風明確，但不要壓過中文歌詞 |

### Weirdness 使用規則

| 數值 | 適用情境 |
| ---: | --- |
| 20%-30% | 抒情歌、家庭溫度、主題曲候選，穩定好聽優先 |
| 35%-45% | Lo-fi、R&B、City Pop、日常感，有一點新鮮但不失控 |
| 50%-60% | Future Pop、Lo-fi Rap、Dream Pop，需要一點特色 |
| 65% 以上 | 第一批先少用，容易犧牲副歌傳唱度 |

### Style Influence 使用規則

| 數值 | 適用情境 |
| ---: | --- |
| 60%-70% | 歌詞與旋律優先，曲風只是氛圍 |
| 70%-80% | 多數 STAR Color 歌曲的安全值 |
| 80%-90% | City Pop、Dance Pop、Future Pop 這種曲風辨識度要明顯 |
| 90% 以上 | 第一批先避免，可能讓中文歌詞被曲風壓過 |

### Exclude Styles 通用模板

第一批若沒有特殊需求，可以先放這組：

```text
heavy metal, screamo, opera, children's choir, harsh EDM drop, aggressive trap, distorted vocals, muddy mix, low quality, noisy master, off-key vocals
```

如果是抒情歌，可再加：

```text
rap, dance club, hard rock
```

如果是快歌，可再加：

```text
slow ballad, sad piano-only, ambient drone
```

```text

```

```text
Weirdness +10%
Style Influence +5%
```

如果整首太怪、不像品牌可以用：

```text
Weirdness -15%
Style Influence -5%
```
