# STAR Color 簡報生成待補素材清單

用途：補齊正式 Logo 與產品圖後，讓後續簡報生成更穩定、更貼近品牌真實資產。

## 優先補齊

- [x] 正式 Logo 透明 PNG
- [ ] 正式 Logo SVG 或 PDF
- [ ] 深色背景用 Logo
- [ ] 淺色背景用 Logo
- [x] AI 智能染髮機正面照
- [ ] AI 智能染髮機側面照
- [ ] AI 智能染髮機操作照
- [ ] App 配方調色介面截圖
- [ ] 顧客色彩紀錄 / CRM 介面截圖
- [ ] 店面招牌照
- [ ] 店內環境照
- [ ] 染髮師操作照

## 檔案命名建議

Logo：

- `star_color_logo_primary_transparent.png`
- `star_color_logo_primary.svg`
- `star_color_logo_dark_bg.png`
- `star_color_logo_light_bg.png`

產品圖：

- `star_color_ai_machine_front.png`
- `star_color_ai_machine_side.png`
- `star_color_ai_machine_operation.png`
- `star_color_app_formula_ui.png`
- `star_color_customer_color_record_ui.png`
- `star_color_store_signage.png`

## 注意

正式素材放入 `assets/logo` 與 `assets/product` 後，請更新 `assets_manifest.json`，並在 prompt 中明確指定可用素材。
