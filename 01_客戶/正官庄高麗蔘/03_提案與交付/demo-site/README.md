# 正官庄 AI 行銷稽核系統 Demo

## 用途

這是提案用靜態 Demo 網站，先用假資料展示內部員工登入、生成系統、稽核系統、SKU 規則庫與管理者審核紀錄。

## 開啟方式

直接用瀏覽器開啟：

`index.html`

公開展示網址：

[https://kgc-ai-compliance-demo.vercel.app](https://kgc-ai-compliance-demo.vercel.app)

## Demo 帳號

- 一般員工：`marketing@kgc.demo`
- 管理者：`admin@kgc.demo`
- 密碼：`demo1234`

登入頁可直接選擇身份，也可以點「以管理者進階登入」。

## 展示流程

1. 一般員工登入。
2. 看儀表板的稽核數量、紅燈攔截、黃燈提醒與待審清單。
3. 進入文案稽核，使用預設高風險文案。
4. 點「開始稽核」，展示紅燈、問題詞標記與安全改寫。
5. 進入文案生成，展示 ChatGPT 生成安全版本。
6. 進入圖像生成，展示 image2 生成流程與圖像稽核。
7. 進入影片稽查，展示時間碼風險表。
8. 切到管理者進階登入，查看完整審核紀錄與管理者設定。

## 第一版範圍

- 靜態 HTML/CSS/JS。
- 使用正官庄 logo 圖檔與公開資料參考圖像。
- 不接真 ChatGPT API。
- 不接真 image2。
- 不接真後端帳號與資料庫。
- 不做真影片辨識。
