# 正官庄高麗蔘

## 專案定位

正官庄高麗蔘 AI 行銷＋稽核系統提案資料夾。

這個案子的核心不是單純做內容生成，而是把「高麗蔘／中藥材／保健食品相關廣告風險」變成一套可展示、可稽核、可留痕的 AI 行銷作業平台。

## 待確認

- [ ] 正官庄台灣實際合作窗口與決策者。
- [ ] 產品 SKU 清單：中藥材、一般食品、健康食品、禮盒、飲品、萃取液是否分開管理。
- [ ] 官方品牌手冊、Logo 原檔、標準色、字體、通路素材。
- [ ] 是否已有內部法務、藥師、藥事顧問或代理商審稿流程。
- [ ] 提案展示網站是否只做 Demo，或要同步規劃 MVP。
