# AI 行銷稽核系統架構

## 系統定位

這是一個架構在 AI 之上的正官庄內部行銷工作入口。所有文案、圖片、影片、廣告與活動頁素材，都先進入 AI 稽核系統，確認沒有明顯法規與品牌風險，再交給人工審核與發布。

## 一句話提案

> 讓正官庄的每一次行銷生成，都先通過法規、品牌、產品 SKU 三層稽核，從源頭降低食藥廣告違規風險。

## 登入與權限

### 角色

| 角色 | 權限 |
| --- | --- |
| 行銷人員 | 生成文案、圖片、影片腳本，送審 |
| 設計人員 | 生成視覺、上傳素材、查看品牌規範 |
| 代理商 | 依任務產出草稿，不可直接發布 |
| 法規／法務 | 審核紅黃燈案件，維護規則庫 |
| 主管 | 查看審核紀錄、通過／退回重要素材 |
| 系統管理員 | 管理帳號、SKU、規則、權限 |

### 登入後首頁

- 今日待審素材。
- 高風險內容提醒。
- 本月生成素材數。
- 本月被攔截風險數。
- SKU 合規狀態。
- 快速建立：文案、圖片、影片稽查、廣告素材。

## 核心功能

### 1. 文案生成

輸入：

- SKU
- 通路：Facebook、Instagram、LINE、官網、廣告、EDM
- 目標：新品、節慶送禮、品牌故事、活動檔期
- 語氣：穩重、溫暖、精品、日常保養

輸出：

- 主文
- 標題
- CTA
- Hashtag
- 風險等級
- 稽核理由
- 安全改寫建議

### 2. image2 圖像生成

輸入：

- SKU 或產品圖
- 主題：父親節、中秋、企業贈禮、日常保養
- 版型：社群圖、廣告圖、官網 Banner、EDM 首圖
- 品牌視覺方向：深紅、金、米白、韓式高級

稽核：

- 圖中文字是否含療效。
- 畫面是否有醫療暗示。
- Logo 是否錯誤。
- 產品是否被變形。
- 色彩是否符合 CIS。

### 3. 影片稽查

輸入：

- 影片檔、字幕檔、腳本或連結。

系統分析：

- 逐字稿掃描。
- 字幕掃描。
- 畫面醫療暗示偵測。
- 時間碼標記。
- 高風險片段截圖。

輸出：

- 風險時間碼。
- 問題句。
- 問題畫面。
- 修改建議。
- 可交付剪輯師的修正清單。

### 4. 廣告送審前檢查

檢查項目：

- Meta／Google 廣告文字。
- 圖片文字。
- Landing Page 標題。
- CTA。
- 產品分類與許可證。
- 誇大或醫療暗示。

輸出：

- 可上線／需修改／禁止上線。
- 修改後替代版本。
- 審核紀錄。

### 5. 合規素材庫

儲存：

- 已核准文案。
- 已核准圖片。
- 已核准影片腳本。
- 可用句型。
- 禁用句型。
- SKU 法規資料。
- 過往退件案例。

價值：

- 新人不用重踩風險。
- 代理商有標準可跟。
- 法規團隊不用每次從零開始審。

### 6. 品牌 CIS 檢查

檢查：

- 色彩。
- 字體方向。
- 語氣。
- Logo 使用。
- 圖像是否符合正官庄高級穩重感。
- 是否過度像一般保健品促銷素材。

## Demo 版本建議

第一階段展示網站不用把所有 AI 都真的接完，可以先做「可點、可演、可看到價值」的 Demo。

### Demo 必備頁面

1. 登入頁。
2. 儀表板。
3. 文案生成＋稽核。
4. 圖像生成＋稽核。
5. 影片稽查報告。
6. SKU 規則庫。
7. 審核紀錄。

### Demo 情境

使用者輸入高風險文案：

> 正官庄高麗蔘幫你改善疲勞、增強免疫力、預防感冒。

系統輸出：

- 紅燈。
- 問題：改善疲勞、增強免疫力、預防感冒。
- 原因：涉及醫療效能或未確認健康食品核准功效。
- 安全改寫：
  - 正官庄高麗蔘，給每天忙碌的你一份溫潤的日常保養。
  - 季節轉換時，把照顧自己變成每天都做得到的小習慣。
