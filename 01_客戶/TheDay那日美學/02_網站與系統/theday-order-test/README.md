# TheDay 那日美學｜分店內部訂購測試版

建立日期：2026-05-24
狀態：可試用測試版

## 用途

讓 TheDay 那日美學分店先試跑內部訂購流程：

- 分店登入測試帳號
- 人員登入測試帳號
- 分店自行下單
- 分店查看自己的訂單紀錄
- 管理者查看全部分店訂單
- 管理者匯出商品彙總與分店明細
- 管理者用 CSV 批次匯入商品

## 開啟方式

### 外出提案公開網址

已上架到 Vercel：

`https://theday-order-test.vercel.app/`

這個公開版適合外出提案展示。資料存在展示裝置的瀏覽器，適合單機跑流程；正式讓各分店共用資料時，需要接 Firebase Auth / Firestore。

### 穩健部署

已新增部署檢查與 SOP：

- `npm run verify`：檢查品項、人員、分店與前端載入狀態
- `npm run deploy:api`：Vercel CLI 卡住時的 API 備援部署
- `部署SOP.md`：GitHub 連動 Vercel 的正式部署流程

若本機沒有 `npm`，可以直接執行 `node scripts/verify.mjs`。

建議改成 GitHub 連動 Vercel 自動部署，避免每次外出前都依賴本機 Vercel CLI。

### 單機看流程

直接用瀏覽器開啟：

`index.html`

### 平板 / iPad 試用

雙擊：

`啟動平板預覽.command`

接著用 iPad / 平板開啟終端機顯示的網址，例如：

`http://192.168.0.xxx:4188/`

注意：平板與這台 Mac 要在同一個 Wi-Fi。這個模式會讓同 Wi-Fi 裝置共用同一份測試資料，分店下單後管理者可以看到彙總。

## 商品資料怎麼進去

商品很多時，不建議一筆一筆 key。

請先向客戶取得 Excel 或 CSV，整理成以下欄位：

```text
品牌,分類,品項名稱,規格,單位,價格,是否上架,備註
```

取得後可在管理者畫面進入「商品管理」，使用「匯入商品 CSV」一次匯入。

少量臨時商品可以直接在「商品管理」手動新增。

## 注意事項

- 直接開 `index.html` 時，資料存在瀏覽器 localStorage，適合單機流程測試。
- 使用 `啟動平板預覽.command` 時，同 Wi-Fi 裝置會共用測試資料。
- 重置資料後，測試訂單會清空。
- 正式版需要接 Firebase Auth / Firestore，才能讓各分店各自登入並共用雲端資料。
