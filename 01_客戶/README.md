存放所有客戶資料、合作狀態、品牌背景、目標、交付項目與溝通紀錄。

## 建議結構

每位客戶可建立一個資料夾：

- `客戶檔案`
- `品牌資料`
- `內容規劃`
- `廣告投放`
- `月報`
- `會議紀錄`

新增客戶時，建議套用 `模板/客戶模板.md`。
